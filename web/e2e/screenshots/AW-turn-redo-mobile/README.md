# AW-turn-redo-mobile

The turn redo UI on phone-sized screens (390x844, 360x740, 412x915, landscape 844x390): the "Redo my
last turn" entry in the event log drawer, the status pill while the replay runs, and the hand-off /
complete / conflict states with Restore and Keep, with a pending dialog and with the turn action bar.

    cd web
    TI4_SHOT_PORT=33101 npm run screenshots -- AW     # after shots, assertions, index.html
    TI4_SHOT_PORT=33101 TI4_SHOT_PREFIX=before npx playwright test -c e2e/screenshots/playwright.config.ts e2e/screenshots/AW-turn-redo-mobile/

The `before-*` PNGs and `metrics/before-*.json` were taken on the base commit (unified-latest-2026-10-08)
with `TI4_SHOT_PREFIX=before`; they are committed and are not regenerated by the default run.

Folder ids are sequential (`A`..`Z`, `AA`..`AV` were taken when this folder was made, so this one is
`AW`); the next folder takes `AX`. Check `git branch -a` before picking an id (see `../README.md`).

- `scenes.ts` the states (mocked turn-redo statuses from `../Q-turn-redo/redoMock.ts`) and the measuring.
- `layout.ts` the assertions: collapsed strip <= 48 px, open sheet <= 40% of the viewport height, nothing
  covered (header, toolbar, seat legend, Players / Events buttons, turn action bar, event log, dialog
  buttons), Restore / Keep >= 44 px and reachable.
- `capture-1-states.ts` 390x844 (all states) and 360x740 (four states), before and after.
- `capture-2-other-phones.ts` 412x915 and 844x390: metrics and assertions.
