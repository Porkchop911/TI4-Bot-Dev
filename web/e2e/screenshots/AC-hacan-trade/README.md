# AC-hacan-trade

The trade desk with Hacan across the table: the note ask shapes on the Promissory Notes tab.
Captures: `capture-*.ts`, one per screenshot; `tradeChoice.ts` is the shared option list. Output: `out/*.png`, captions in `manifest.json`; `index.html` is generated from it.

Rerun: `cd web && npm run screenshots -- AC`
