# AP-hidden-reaction-wait

Captures: `capture-1-waiting-banners.ts` (imports `../_shared`). Output: `out/*.png`, listed with captions in `manifest.json`; `index.html` is generated from it.

Rerun: `cd web && npm run screenshots -- AP`

The `before-*` PNGs were taken on the base commit with `TI4_SHOT_PREFIX=before` and are committed; the `after-*` PNGs are regenerated by the runner. Folder ids are sequential (A..Z, AA..AZ, BA...): take the next free id after the highest one on any branch you merge with.
