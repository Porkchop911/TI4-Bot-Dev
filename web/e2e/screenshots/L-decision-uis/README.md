# L-decision-uis

Dedicated UIs for decisions that used to fall back to the plain option list (see `docs/UI_DECISION_COVERAGE.md`).
Captures: `capture-*.ts`, one per screenshot, importing `../_shared`. Output: `out/*.png`, listed with captions in `manifest.json`; `index.html` is generated from it.

Rerun: `cd web && npm run screenshots -- L`
