# SCPT 467 Ultimate Guide to the Mahact Gene-Sorcerers (2026-07-29, Hunter + Blasto) — own transcription base.en, 1:30-2:08 (no chapter list; range guessed)
- Draft: need resources-heavy slice (2-2 double systems, Abyss/Freya-type 3-planet); Bio-Stims is the star of the early game; tricky to draft: only first-pick Mahact if all slices are fine. Sit next to Crimson/Deepwrought if in game; sacrifice speaker spots to be adjacent to the Entropic Scar. Speaker as Mahact -> Trade R1 is a very different (better) start; otherwise prefer slice over speaker order.
- Strengths: best mech, best leader suite (commander from others' tokens; Benediction + Star Lancers + commander = 3 closers), breakthrough synergy, X-89. Weakness in TE: faster game = ticking clock; not fast (no blue start/movement) — Barony gets to Rex/Styx first; one of the best Styx factions (Benediction solves air) but loses to ground roots (Arborec, Yin+Yin Spinner) unless X-89. Good at control stage IIs with saved tokens.
- Don't forever-war a Mahact; throw wrenches in MID game, not end.
- Token habits: save tokens rather than spending all every round; make each activation accomplish multiple things (fight to capture tokens: ship of one faction + planet of another = two commanders); ask Deepwrought to use their agent on you to get their token.
- R1 cards: TRADE best (solves money; follow tech; score spend objective; build). CONSTRUCTION underrated (Hunter): controlled build + forward dock; Mahact skips the Warfare secondary (Warfare usually goes first action and Mahact only has 3 resources at home — can't build carrier+infantry). LEADERSHIP mid (4th-5th). WARFARE primary: Blasto likes (take a 3rd system without Warfare secondary; dreadnought in range of Rex R2), Hunter dislikes (spreads thin vs hostile table). TECHNOLOGY mid/low (saves 4 resources + token; DT, or Hyper Metabolism R1 if blue skip, purge later). DIPLOMACY low unless last pick with spend objective (Mahact can follow 3 secondaries R1: 2 tokens + agent). POLITICS: don't chase custodians as Mahact (influence focus wrong; heat); take Rex R3 after someone else; but take Politics 5th pick over others if no one goes for custodians. IMPERIAL never R1.
- R1 custodians via Cruiser II (Tech primary + red skip) — usually a trap (don't then build cruisers; skirmisher with no late game).
- Core tech: Gravity Drive, Carrier II, Fleet Logistics (best Fleet Log faction, "S+"), X-89; then Light/Wave (to bypass Fracture blockers), Transit Diodes (Hunter: reposition Star Lancers by surprise), Fighter II, Integrated Economy last. Path: blue skip -> Hyper R1, then GD, Sling->Fleet Log->Carrier II, X-89; else DT/Antimass first.
- Agent sales: sell early in round so people plan for it; take money (>=2 in R1; 1 later). Plan: R1 build plastic (R1 plastic takes Rex R3), dock, fighters, Carrier II, Star Lancers; bonus point mid game (Imperial R3) then Styx.
