# SCPT 472 Ultimate Guide to the Council Keleres (2026-09-02, Hunter + JJ) — own transcription base.en, 1:54-2:23
- Strength: economy that revs up (Agency Supply Network, tradeable Keleres Rider promissory); hero can swing ~3 points (Mecatol -> Styx in one turn). Weakness: very bad starting units (tech start ok); weak at the Fracture; value depends heavily on table attitude (people block Keleres on Rex even at no gain).
- Default win plan: Agency Supply Network -> take Mecatol Rex as staging area -> Styx. Needs early access/forward dock.
- R1 cards: CONSTRUCTION high (no breakthrough tie-in; home build fixes infantry shortage; forward SPACE DOCK (not PDS) towards Rex; want straight-shot slice). TECHNOLOGY high (JJ: consider first pick — lots of tech needs; being after Warfare is good since starting fleet is fine and Warfare's home build gives infantry; double tech possible with Mentak-home start, single tech + R1 Rex sometimes). POLITICS (Hunter: blue start; discard action cards to keep commodities; R2 custodians with IIHQ breakthrough building 3 on Rex). TRADE great (do breakthrough with a tactical action then Trade for money). LEADERSHIP middle (breakthrough via 3 TG council patronage first action; spend extra token into Entropic Scar for faction tech). DIPLOMACY very low (already rich; nothing to spend on). IMPERIAL never R1. WARFARE disliked — but if no one else takes it you must ensure a home build: R1 production for infantry is mandatory (paranoid: grab Warfare if Construction gone and Warfare would be skipped; use primary on home build, never to spread out thin).
- Core tech: Gravity Drive, Executive Order (Hunter dislikes), Agency Supply Network, Carrier II, X-89 (+Bio-Stims). Sarween not needed. Fleet Logistics big for Keleres (unlocked build + move = action-phase win). Fighter II as second unit upgrade; Light/Wave to enter Fracture late; buy Jol-Nar research agreement every round; follow Deepwrought breakthrough. Space Dock II optional. Dreads pointless; carriers + fighters ("cardboard faction").
