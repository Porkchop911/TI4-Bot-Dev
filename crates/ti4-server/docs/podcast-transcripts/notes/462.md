# SCPT 462 Ultimate Guide to Scoring and Tempo (2026-06-24, Hunter + Blasto) — own transcription base.en
- 0:00-0:14 banter; secret bluffing: behave the same whether or not secrets are scoreable; hold action-phase secrets until last moment (scoring reveals threat); never show secrets.
- 0:10 scoring two objectives simultaneously (edge + empty systems) hides threat; opponents miscount.
- 0:14 key skill: quickly size up each player's scoring potential THIS round. "Most points" != "the lead"; tempo > point total. Two players at 8: one has all 3 secrets scored + undoable stage 2 = dead; other has custodians + support + scoreable secrets = wins maybe in action phase.
- 0:18 Thunder's Edge: assume all secrets scoreable; game became a race; winslaying rarer because of time; old-fashioned point blocking (e.g. retake Mecatol Rex with 1 token + carrier/2 inf to deny Imperial's MR point) is cheap and effective. Example: lone infantry on MR left unchallenged gave Hunter an extra Imperial point.
- 0:21 Blasto vs Hunter disagreement-ish: "boat floating"/mutually-assured-destruction threats overused; Hunter: accept a loss of tempo when blocked, then redirect table to next leader.
- 0:24 defend home when ahead; leave a destroyer/fighter behind when carrier leaves (keep home "gummed" so it can't be taken without a fleet/light-wave). Early attacks only if decisive (eliminate/cripple).
- 0:28 read the draft: high-tempo factions -> be one of the tempo players.
- 0:29 point sources: publics (stage I 1VP, stage II 2VP; one per status phase + Imperial/overrule/Winnu hero), secrets (3 max; action-phase secrets can all be scored in one round, status-phase one per round, agenda-phase as qualified), bonus points (custodians, Shard (sticks), support for throne, Crown of Emphidia (score round 3), Book of Latvinia, mutiny, Seed of Empire, Political Censure).
- 0:33 supports: both hosts prefer games without support swaps; Hunter only engages when others start; Blasto: once started, swap early; "Empyrean pattern": take Rex -> extort a support -> go for Shard.
- 0:52 speaker tempo was over-important in PoK; now: just have Imperial once (round 2-3), not repeated Politics. Platonic 4-round game: R1 Politics, R2 Leadership (custodians R2), R3 Imperial (other public), R4 Warfare (to Shard/Styx point).
- 0:56 old PoK "speaker control" (Politics R3->R4 to be speaker R5) is obsolete in TE; games end R4/R5 before Imperial-on-R5 matters.
- 1:00 scoring tempo = points + scoring POTENTIAL next round (bonus pts, secrets in hand, action-phase>status). Player at 9 with no secrets less scary than player at 5 with Imperial + 3 secrets.
- 1:02 everything gated per round: 1 action card/round, production cap, tech ~1/round (guides recommend 4 techs = 4 rounds), structures only via Construction -> build structures early in case structure objectives flip.
- 1:05 R1 strategy-phase mistakes lose games (e.g. Sol 2nd pick not taking Politics).
- 1:06 drafting: pick strongest faction; predict who can take custodians R1 (Saar nearly always); counters (Crimson hard-counters Barony sustain; Benediction counters Hacan/Mahact...); Styx is rock-paper-scissors.
- 1:11 custodians R1 requires 6 influence available, not just reach; zero-influence-home factions (Barony) must spend whole slice.
- 1:12 SECRET KEEP RULE: keep action-phase secret ~99% (Hunter) unless near impossible (become a martyr, last to pass vs Crimson stalls, destroy greatest...). Blasto: keep a status-phase secret over a questionable action one if it is scoreable by R2 status — secret tempo: secrets in R2,R3,R4 status -> otherwise last secret only R5. Mild disagreement.
- 1:19 R1 strategy pick: first question "can I take custodians R1?" Factions that can: Saar, Deepwrought, Jol-Nar, NRA (Trade -> Cruiser II), Mahact w/ red skip, Argent (Gravity drive R1) ; list expands with Warfare primary and Diplomacy.
- 1:21 custodians vs scoring R1 public: usually custodians (bonus point not costing secret tempo; publics can be caught up with Imperial). Exception: take Construction R1 when structure objectives out so R2 Imperial double-scores.
- 1:27 PSA: prioritise custodians R1 and TAKE IMPERIAL ROUND 2; if Imperial is left untaken someone erred. Consider Imperial first each strategy phase. Gives others secrets but double-score better for you.
- 1:31 higher tempo = more options; ahead-of-tempo knocked back is still on tempo.
- 1:33 late game: Styx, casino paths (relics), re-take Rex if Imperial left again, Public Disgrace.
- 1:34 Empyrean underrated (good on ground: blue-green, X-89); Deepwrought underrated, Crimson slightly overrated (top tier but lower).
- 1:41 canonical 10: 5 publics + 3 secrets + custodians + Styx; or 5P+3S+Imperial MR point+Styx; "manipulator": 4P+3S+support+custodians/Styx. Need >=1 bonus point always.
- 1:42 when behind on tempo take risks: grab relics, extort supports from cool-guy leader.
