# Podcast transcripts

Machine transcripts (faster-whisper `base.en`, CPU, no speaker labels) of the sampled episodes
used for `../PODCAST_STRATEGIES.md`: Space Cats Peace Turtles (SCPT) and Radio Mecatol. File names
are episode numbers; a `range` header marks which time span of the episode was transcribed
(not whole episodes). `notes/` holds the per-episode summary notes. Coverage is a sample, about
3% of SCPT; see section 1.3 of the doc. The recordings and the words belong to their creators;
these transcripts are kept here as research material for the bot work.
