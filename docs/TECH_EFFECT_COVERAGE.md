# Technology effect coverage

Generated from `crates/ti4-content/content/technologies.json`; one test per effect in `crates/ti4-engine/src/technology_effects_tests/` (`g1` generic, `g2`-`g4` faction techs). Test names are `<tech id>_<effect no.>_<what>`.

Status: `pass` = engine implements it and the test shows it; `ignored` = the test is written but `#[ignore = "MISSING: ..."]` because the engine lacks or misimplements the effect (run `cargo test -p ti4-engine --lib technology_effects_tests -- --ignored` to list them).

## Missing or broken effects

None. Self-Assembly Routines (`sar`, rules version 13), Antimass Deflectors 2, Psychoarchaeology, Magen Defense Grid 1 and 2, AI Development Algorithm, Predictive Intelligence and Infantry II (all behind `RULES_TECH_EFFECTS`, rules version 15) are implemented; every test passes and none is ignored. Legacy games (below the gating version) play without them.
