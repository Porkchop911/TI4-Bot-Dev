## Repetition protocol

### Repetition counts
| Benchmark | Repetitions | Rationale |
|---|---|---|
| Single-core four-round game | 50 | Low variance expected |
| Fixed-worker throughput | 50 | Throughput stable after warmup |
| Policy scoring | 100 | Policy inference has more variance |
| Snapshot/fork | 100 | Memory allocation variance |
| Stage 2 training throughput | 30 | Training has inherent variance |
| Peak memory per worker | 10 | Memory measurements are noisy |

### Interleaving
- Run Python and Rust benchmarks interleaved (not batched) to avoid systematic bias.
- Alternate: Python iteration 1, Rust iteration 1, Python iteration 2, Rust iteration 2, etc.
- Randomize order within each pair.

### Measurement
- Wall-clock time per iteration (high-resolution timer).
- Record min, max, mean, median, std dev, p50, p95, p99.
- Record GC pause times (Python reference code).
