# M00-012b — Fixed repetitions and interleaving

For each semantic-qualified workload, collect 30 timed samples per implementation. The planned
execution order is a deterministic balanced sequence: for pair index `i`, run Python then Rust when
`i` is even, Rust then Python when `i` is odd. The per-implementation seed is the manifest seed
plus `i`; both sides receive the same seed for each pair.

Each sample records monotonic elapsed time in nanoseconds, not wall-clock time. Compute min, max,
mean, median, sample standard deviation, p50, p95, and p99 from all 30 raw samples. Do not discard
outliers. A failed sample invalidates the entire paired benchmark run.
