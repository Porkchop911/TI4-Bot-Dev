## Promissory notes (from `engine/promissory.py`)

### Support for the Throne end-to-end
- Note given to opponent during action phase
- Opponent can call note during their turn
- Note effect resolved immediately
- Note returned to owner after resolution

### Current content-only boundary
- Only currently implemented notes supported
- New notes added to content, not code
- Note effects registered in reaction system

### Note format
```
PromissoryNote {
    id: String,
    owner: PlayerId,
    alias: String,
    effect: Callable[[Game, PlayerId], Option>,
}
```

### Note lifecycle
1. Given to opponent (transaction)
2. Opponent holds note (hidden from others)
3. Opponent calls note (action)
4. Note effect resolved
5. Note returned to owner
