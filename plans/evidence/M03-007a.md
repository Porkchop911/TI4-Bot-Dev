## Implementation

- `parse_bounded_trace` verifies schema version `1.0.0`, the frozen oracle commit, the
  `bounded_game` export scope, positive bounded rounds, and distinct non-empty seats.
- It preserves `choice.selected` values in NDJSON order and parses the required final dice entropy
  record into typed roll entries. State, event, and outcome projections are deliberately ignored
  for this translator slice because native semantic replay belongs to M03-007c.
- Missing selected choice IDs, malformed JSON, unsupported record types, missing/final-position
  entropy, and seed disagreement produce typed errors without partial output.

## Tests added

1. Valid bounded trace exposes header inputs, ordered selected IDs, and dice faces.
2. A moved oracle commit is rejected.
3. Non-adjacent duplicate seats are rejected.
4. A choice lacking a selected option is rejected with its NDJSON line number.
5. Missing final entropy and entropy/header seed mismatch are rejected.
6. Valid negative Python integer seeds are preserved rather than narrowed to Rust-native RNG
   unsigned-seed semantics.

## Live source inspection

With the oracle guard passing and `PYTHONDONTWRITEBYTECODE=1`, a bounded
`save54_base`, seed `7`, one-round oracle run emitted a header, state, choices, events, final
state, and final `entropy` record. The entropy record was `stream: dice`, used seed `7`, and its
roll entries contained `reason`, `faces`, `hits_on`, and `rerolled`, matching the parser contract.
A second run with seed `-7` succeeded and emitted `-7` in both header and entropy records, so the
translator preserves signed source-seed metadata.
