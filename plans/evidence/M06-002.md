## Trade economy (from `engine/transactions.py`, trade tests)

### Commodities
| Field | Description |
|---|---|
| `commodities` | Player's commodity count |
| `trade_goods` | Player's trade good count |
| `trade_value` | Current trade value per commodity |

### Trade goods
- Gained from strategy cards, trade actions, objectives
- Spent on production, technology research
- MC technology: 1 trade good = 2 resources

### Replenishment
| Source | Effect |
|---|---|
| Strategy card | +1 trade good per unclaimed card |
| Objective | +N trade goods |
| Action card | +N trade goods |
| Trade action | +N trade goods |

### Exchange
- Commodity → trade good conversion
- Trade good → commodity conversion
- Exchange rate determined by game state

### Transaction validation
- Each transaction validated before execution
- Invalid transaction → no state change
- Transaction limits enforced (once per neighbour per turn)
