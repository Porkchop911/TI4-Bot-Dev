## Landing choices (from `engine/invasion.py`)

### Cargo-to-planet assignment
| Rule | Description |
|---|---|
| Active system planets | Ground forces land on planets in active system |
| Multi-planet | Can land on multiple planets |
| Atomic landing | All landings atomic (all or nothing) |

### Multi-planet order
- Planets sorted by id (deterministic)
- Player chooses which planets to land on
- Order of landing matters for planet control

### Atomic landing
- All ground forces committed together
- If invasion fails, no forces lost
- If invasion succeeds, all forces on planets

### Landing option format
```
Option(
    id=f"land|{planet_ids}",
    kind="land",
    label=f"land {count} ground forces on {planets}",
    payload={"planets": [planet_id, ...], "forces": count}
)
```
