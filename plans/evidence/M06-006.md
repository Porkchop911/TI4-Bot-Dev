## Exploration decks (from `engine/exploration.py`)

### Draw
- Draw from exploration deck when Dark Energy Tap technology used
- Deck built from sources (POK + current codex)
- Seeded shuffle for reproducibility

### Resolve
- Exploration card resolved immediately
- Effect depends on card type (explore, purify, fragment)
- Effect applied to game state

### Purge/discard
- Explored cards moved to discard pile
- Purge = remove from game (certain cards)
- Discard = available for reshuffle

### Fragments
- Fragment tokens placed on frontier tokens
- Fragments collected for relic deck
- Fragment count per player tracked

### Attachments
- Exploration attachments modify planet values
- Core Mining, Senate Sanctuary, Terraforming Initiative
- Applied in planet_value_now()

### Registry coverage
- All exploration cards in registry
- All effects registered
- All fragments tracked
