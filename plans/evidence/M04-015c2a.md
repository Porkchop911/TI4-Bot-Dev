## Implementation

- Added `import_initial_public_state`, a strict deserialization boundary for the source public schema.
- It validates the state record type, stable seat/player ordering, and only accepts initial-style
  strategy state: no held cards and seating-order initiative. The source projection does not expose
  strategy-card initiative metadata, so accepting a held card would create a native state with an
  invented initiative order.
- It reconstructs public player, board, agenda, token, law, unit, and card-count state. Private
  action-card and secret-objective identities use opaque deterministic placeholders, which are
  never exposed by the public projection.
- Before returning, the importer invokes M04-015c1's strict comparator. A source inconsistency or
  unsupported public field cannot become an apparent successful import.

## Tests and compatibility evidence

1. `trace-001` imports with no public difference.
2. Every one of the 100 retained initial snapshots imports with no public difference.
3. A held strategy card is refused because the source snapshot omits the initiative metadata that
   native ordering requires.

This proves exact reconstruction of retained **initial public states only**. It does not prove a
native game can run from them or that any source decision, die result, event, final state, or outcome
is equivalent.
