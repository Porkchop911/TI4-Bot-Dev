### Verification process
1. Export each game using the Oracle exporter (M00-009).
2. Capture all entropy (dice rolls, deck shuffles, random calls).
3. Replay each game using the captured entropy.
4. Verify byte-identical output between export and replay.

### Verification commands
```bash
# Export 100 games
for i in $(seq 1 100); do
  python tools/oracle_export.py --game-id game_$i --seed $i --output out/export_game_$i.ndjson
done

# Replay 100 games
for i in $(seq 1 100); do
  python tools/oracle_replay.py --input out/export_game_$i.ndjson --output out/replay_game_$i.ndjson
done

# Verify byte-identical output
for i in $(seq 1 100); do
  diff out/export_game_$i.ndjson out/replay_game_$i.ndjson || echo "MISMATCH: game_$i"
done
```

### Expected results
- All 100 games export and replay identically.
- No drift between export and replay.
- All entropy captured and replayed correctly.
