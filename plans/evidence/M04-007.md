## Turn order and passing (from `engine/game.py`)

### Initiative order
- Determined by strategy card initiative (lowest first)
- Stored in `GameState.initiative_order: Vec<PlayerId>`
- Computed at game start from strategy card setup

### Active player
- Player whose turn it is
- Set by `_begin_action_turn(player_id)`
- Cleared to None when all passed or round ends

### Strategic action before pass
- Player cannot pass until they have performed their strategic action
- `player.strategy_card_exhausted` must be True before pass available
- `unused_strategy_cards` determines if strategic action available

### Multi-card handling
- 3/4 player games: 2 strategy cards each
- Player chooses which card to exhaust first
- Other card remains available for later turn
- Option id: `"strategic|{card_id}"` for card-specific action

### Turn advancement
```
_advance_turn(allow_fleet_logistics=True):
    if fleet_logistics and current player:
        return (keep turn)
    if current: technology.end_turn(current)
    clear_transactions()
    if all_passed: active = None
    else: find next non-passed player in initiative order
    _begin_action_turn(next_player)
```

### Fleet Logistics exception
- Technology "lgf" (Fleet Logistics) can retain turn
- Checked via `technology.retain_turn_with_fleet_logistics`
- Only applies when `allow_fleet_logistics=True`

### Pass mechanics
- `state.with_player(player_id, passed=True)` marks player passed
- `state.passed` cleared at status phase start
- Player with strategic token can still act after passing
