### Legal ship subsets
- Ships of a player in a system
- Ships that can retreat (move value > 0)
- Ships that can fight (all ships)
- No combinatorial duplicates (distinct_units by type + damage)

### Fleet enforcement
```
enforce(game, player, system_id):
    if not in_supply(player, system_id):
        destroy_all_ships(player, system_id)

enforce_capacity(game, player, system_id):
    for each planet in system:
        fighters = count_fighters(planet)
        capacity = sum(unit.capacity for unit on planet)
        if fighters > capacity:
            remove_excess_fighters(fighters - capacity)
```

### Supply check order
1. After combat (fleet.enforce)
2. After production (fleet.enforce)
3. After movement (fleet.enforce_capacity)
