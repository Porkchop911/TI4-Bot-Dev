## Faction seating/setup (from `engine/factions.py`, `engine/game.py`)

### Player order
- Determined by strategy card initiative (lowest first)
- Seating order: clockwise from speaker
- Both orders stored in GameState

### Home systems
| Property | Source | Notes |
|---|---|---|
| `home_system` | faction record | System id |
| `home_planets` | planet records | Planets with `factionHomeworld` |
| `starting_fleet` | faction record | Fleet composition |
| `starting_tech` | faction record | Starting technologies |
| `starting_tokens` | faction record | Starting tokens by type |
| `starting_cards` | faction record | Starting strategy cards |

### Deployment (factions.deploy)
1. Place home fleet in home system
2. Set player home_system, home_planets
3. Set player starting fleet, tech, tokens, cards
4. Verify home system exists in galaxy

### 3p/6p projections match
| Aspect | 3-player | 6-player |

| Starting fleet | Per faction | Per faction |
