## Coverage harness (cargo-llvm-cov)

### Commands
```bash
# Install
cargo install cargo-llvm-cov

# Run with coverage
cargo llvm-cov --workspace --all-targets --all-features --lcov --output-path lcov.info

# Generate HTML report
cargo llvm-cov --workspace --all-targets --all-features --html --output-dir coverage

# Check coverage threshold
cargo llvm-cov --workspace --all-targets --all-features --ignore-filename-regex='xtask|ti4-cli' --lcov --threshold 85
```

### Coverage gates
- **Workspace minimum:** 85% line coverage
- **Critical modules (state, timing, payments, replay):** 95% line coverage
- **Report location:** `coverage/index.html` (HTML), `lcov.info` (CI artifact)

## Mutation harness (cargo-mutants)

### Commands
```bash
# Install
cargo install cargo-mutants

# Run mutation testing
cargo mutants --workspace --all-targets --all-features --timings -- --test-threads=1

# Run on critical crate only
cargo mutants -p ti4-engine --timings -- --test-threads=1
```

### Mutation gates
- **Critical modules:** 90% mutation score
- **Other modules:** 80% mutation score
- **Report location:** `cargo-mutants-report.json`
