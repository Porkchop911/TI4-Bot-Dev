## Victory sources and finish (victory tests/game)

### Attribution
| Source | Attribution |
|---|---|
| Public objectives | VP from scored objectives |
| Secret objectives | VP from scored secrets |
| Support points | VP from promissory notes |
| Custodians | VP from custodians control |
| Tech bonuses | VP from technology |

### Support points
- Promissory notes held by other players
- Each note = 1 VP to holder
- Calculated at game end

### Custodians
- Custodians token tracks control
- When custodians removed → agenda phase
- Custodians control = VP at game end

### Target VP
- Target VP = 10 (standard)
- First to reach target → game ends
- Target can be modified by objectives

### Winner timing
- Game ends immediately when target reached
- Winner declared at end of current step
- Tie-breaking: highest VP, then most techs, then most units
