# M04-008 — Generic strategy primary

## Package specification

- **Milestone / dependencies:** M04; M04-005 through M04-007 complete.
- **Objective:** Generate structural strategic-action choices and atomically exhaust exactly the
  selected strategy card, without implementing card-specific primary effects or secondaries.
- **Python oracle:** `engine/game.py`: `Game._action_options` and `Game._take_action`;
  `tests/test_three_player_strategy.py` and `tests/test_strategy.py`.
- **Oracle revision:** `37061c511a4780d4c0719e0342533a498cd4b457`
  (`codex/fully-learned-policy`), verified clean before implementation.
- **Permission class:** P1. Writable paths were `crates/ti4-engine/src/strategy.rs`,
  `crates/ti4-engine/src/draft.rs`, `crates/ti4-engine/src/lib.rs`, this evidence file, and
  `plans/EXECUTION_STATE.md`. No network, external process, artifact, or external-state effects.

## Implementation and invariants

- One unused card exposes the compatible bare `strategic` action id. Multiple unused cards expose
  stable `strategic|<strategy-card-id>` ids labelled from the content store.
- The shared choice validator rejects invented, malformed, and stale action ids before mutation.
- A valid action exhausts only the selected card. The bare action resolves the first currently
  unused card, matching the oracle rather than assuming the initiative card.
- Card-specific primary effects, secondaries, normal-action selection, turn advancement, and phase
  completion are explicit non-goals for this structural package.
