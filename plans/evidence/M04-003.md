### Versioned seeded shuffle
```python
def build_deck(seed, sources) -> list[dict]:
    records = content.load(category)
    filtered = [r for r in records if r["source"] in sources]
    rng = random.Random(seed)
    rng.shuffle(filtered)
    return filtered
```

### Explicit entropy alternative
- Same seed → same shuffled order (PCG32 or Python Random)
- Golden vectors: first 100 shuffle results for each deck
- Version rejection: if algorithm changes, old seeds produce different results

### Deck conservation
- Total cards = content records (filtered by sources)
- Drawn cards removed from deck, never duplicated
- Shuffled deck = permutation of original records
- Test: `len(deck) + len(hand) + len(discard) == original_size`
