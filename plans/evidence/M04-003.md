# M04-003 — Deck construction

## Package specification

| Field | Value |
|---|---|
| Milestone / dependencies | M04 / M02 content and M03-006 native RNG complete |
| Objective | Build all setup decks deterministically, reveal two public objectives, and deal each player one secret objective. |
| Oracle sources | `engine/game.py:start_game`; `engine/objectives.py:starting_deck`; `engine/action_cards.py:build_deck`; `engine/agenda.py:build_deck`; `engine/exploration.py:build_decks`; `engine/relics.py:build_deck`; `engine/secrets.py:build_deck` |
| Oracle commit | `37061c511a4780d4c0719e0342533a498cd4b457`, verified clean before implementation |
| Allowed edits | `crates/ti4-engine/src/{deck,setup,lib}.rs`, this evidence file, and `plans/EXECUTION_STATE.md` |
| Permission | P0 read-only oracle inspection; P1 Rust source, tests, evidence, state, local branch and commit. No network or external-state effects. |

Inputs are a `ContentStore`, `SourceSet`, player ids, and a native `u64` seed.  The output is
a `GameState` containing ordered decks, two revealed stage-I objectives, and exactly one
secret in each seated player's hand.

## Invariants and non-goals

- Catalogues are source-scoped then sorted by id before shuffle, matching the oracle's
  catalogue construction. Public objectives are five shuffled stage I followed by five
  shuffled stage II.
- The four exploration decks are independently partitioned by `CULTURAL`, `HAZARDOUS`,
  `INDUSTRIAL`, and `FRONTIER`; fake relics are excluded.
- Shuffles use the pre-existing versioned native `GameRng` domains. They are deterministic
  and isolated from dice and from one another.
- Native seed order is a compatibility class of **intentional change**: it is not an
  oracle golden order because the approved native RNG is ChaCha8, while Python uses
  Mersenne Twister. Source membership, stage boundary, setup effects, and reproducibility
  are semantic compatibility evidence. Legacy entropy translation remains M03-007.
- No draw/discard reshuffle rules, card effects, status draw, agenda resolution, hidden-view
  work, or Python RNG emulation were added.
