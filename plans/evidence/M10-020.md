## Implementation

### `Checkpoint` struct (schema 1)
Matches the oracle's checkpoint format from `tools/train_stage1_policy_gradient.py`:
```json
{
  "schema": 1,
  "trainer": "teacher_free_stage2_policy_gradient",
  "stage": 2,
  "horizon": {"rounds": 4, "steps": 500000},
  "arguments": {"seed": "0", "games": "100"},
  "resumed_from": null,
  "final_update": 42,
  "run_complete": false,
  "profiles": {"sol": <Profile>, ...},
  "accepted": {"sol": <Profile>, ...},
  "history": [],
  "training_telemetry": [],
  "checkpoint_archive": {},
  "audit_metrics": null,
  "learner_audit_metrics": null
}
```

Key design decisions:
- `skip_serializing_if` + `default` on all optional fields for forward/backward compatibility
- SHA-256 checksum in a companion `.sha256` file (separate from the JSON for atomicity)
- Schema version checked on both save and load
- `resumed_from` records the source checkpoint's trainer name

### `Archive` struct
- `save()`: serializes → writes `.tmp` → writes `.sha256` → atomic rename
- `load()`: reads `.sha256` if available, verifies checksum, validates schema
- Interrupted temp file detection: if `<path>.tmp` exists alongside `<path>`, load fails with `InterruptedTemp`
- `exists()`: checks path exists and no temp file is present

### Supporting changes
- `Horizon` in `rollout.rs`: added `Serialize` + `Deserialize` derives
- `Run` in `stage1.rs`: added `Serialize` + `Deserialize` derives (was missing)
