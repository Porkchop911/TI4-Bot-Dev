## Implementation

- Added ti4_legacy::state_projection and canonical_state_bytes.
- The projection matches the source record shape: phase/turn/round context; seating and derived initiative order; public player facts; sorted board systems and units; strategy state; agenda/law state; and the finished flag.
- Action-card and secret-objective identities are represented only by counts, matching the source redaction boundary.
- Unit ordering uses the exact source key (owner, type_id, sustained_damage). Source-only fields that Rust cannot yet represent, such as unmodeled public player fields, are not fabricated.
- The parent M04-015 evidence is split into 015a/015b/015c. The owner authorized this M04 work despite M03-007c's dependency-order conflict on 2026-08-12.

## Tests

1. A nontrivial native state projects into the source schema with initiative order, public board ownership, unit sorting, laws, and card-count redaction.
2. Hidden action-card and secret-objective IDs never occur in the serialized public bytes.
3. Repeated projection encoding is byte-stable and parses to the projected JSON value.
4. The complete source projection suite still passes (19 tests).
