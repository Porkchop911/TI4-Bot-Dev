# M00-012d — Benchmark report schema

Each result is an UTF-8 JSON object with schema version `1.0.0`. The raw report is an ignored local
artifact; its SHA-256 and summary may be committed in evidence. Required fields are:

```json
{
  "schema_version": "1.0.0",
  "benchmark_id": "string",
  "implementation": "python|rust",
  "oracle_commit": "40-hex-or-null",
  "rust_commit": "40-hex-or-null",
  "host": {"os": "string", "cpu": "string", "logical_processors": 0, "affinity": "string"},
  "workload": {"fixture_id": "string", "seed": 0, "workers": 1, "semantic_gate": "pass|fail"},
  "warmup_iterations": 10,
  "samples_ns": [0],
  "statistics_ns": {"count": 30, "mean": 0.0, "median": 0.0, "stdev": 0.0, "min": 0, "max": 0, "p50": 0.0, "p95": 0.0, "p99": 0.0},
  "variance": {"stdev_pct": 0.0, "p95_minus_p50_pct": 0.0, "accepted": true},
  "captured_at_utc": "RFC3339 timestamp"
}
```

`captured_at_utc` is audit metadata and is excluded from hash/equality comparisons. Reports must
contain raw samples so a claimed aggregate can be recomputed.
