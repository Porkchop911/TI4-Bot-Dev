## Native RNG (from `engine/dice.py`, `engine/sim.py`)

### RNG algorithm
- **Algorithm**: PCG32 (Permuted Congruential Generator)
- **Variant**: `pcg32` with domain-separated streams
- **Python equivalent**: `random.Random(seed)` for deciders, `dice.RNG(seed)` for game

### Domain-separated streams
| Stream | Purpose | Seed derivation |
|---|---|---|
| `dice_rolls` | Dice resolution | `seed ^ 0x1A2B3C4D` |
| `deck_shuffles` | Deck shuffling | `seed ^ 0x5E6F7A8B` |
| `random_decisions` | Random decider | `seed ^ 0x9C0D1E2F` |
| `exploration` | Exploration deck draws | `seed ^ 0x3A4B5C6D` |
| `relic_draws` | Relic deck draws | `seed ^ 0x7E8F9A0B` |
| `agenda_draws` | Agenda deck draws | `seed ^ 0xBCD0E1F2` |
| `secret_draws` | Secret objective draws | `seed ^ 0xF3A4B5C6` |
| `action_card_draws` | Action card draws | `seed ^ 0x17D8E9FA` |

### Golden vectors
- For each seed, record first 100 random values per stream
- Verify Rust produces identical values to Python `random.Random(seed)`
- Version rejection: if algorithm changes, old seeds produce different results

### Legacy seed conversion
- Python seeds are `int` (32-bit or 64-bit)
- Rust seeds are `u64`
- Conversion: direct cast (Python seeds are always non-negative)
