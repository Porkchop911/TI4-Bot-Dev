## Policy observation API (from `engine/views.py`, bot game proxy)

### Typed authorized observation
- `view_for(state, viewer)` returns redacted GameState
- `redact_player(player)` replaces private sequences with HIDDEN markers
- `HIDDEN = "?"` — not a valid alias, so lookups fail safely
- Private sequences: `action_cards`, `secret_objectives`
- Public counts survive; identities do not

### Compile/API design prevents direct hidden-state access
- GameView delegates non-state queries to real game
- Bot cannot compute legality from view alone
- Bot must ask engine for legal options
- `leaks(state, viewer)` checks for information leaks

### View structure
```
GameView {
    _game: Game,
    _viewer: PlayerId,
    _cached_from: Option<PlayerId>,
    _cached: Option<GameState>,
}
```
