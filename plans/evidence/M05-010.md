## Invariants

- A matching `combat_bonus_round` improves only that player's rolls in that exact combat-round
  sequence; it is read, never cleared by a combat exit path.
- A matching `extra_die_round` adds exactly one die to the selected unit type, once per round.
- A matching `munitions_round` rerolls only misses from this player's **space-combat** batch;
  both the original and replacement rolls remain in deterministic dice history.
- Effective thresholds, grouping, and roll order stay deterministic and use no hash-map order.
- A marker from a different round or player has no effect.

## Explicit non-goals and split rationale

M05-010 originally groups effect sources with the combat roll mechanics. The mechanics can be
implemented now because `PlayerState` already carries the sequence-scoped markers. Playing
Morale Boost or opening/paying the Munitions Reserves reaction window cannot: Rust has no
reaction/event resolver yet, and that is M06-016's declared responsibility. This package does
not invent a direct action-card path or claim those effects are playable. M05-010b remains for
source registration and reaction-window integration after M06-016.

## Implementation and compatibility evidence

- `effective_hits_on` reads `combat_bonus_round` against `GameState::combat_round_seq`.
  It improves only the matching player's current space-combat threshold and needs no cleanup
  branch to lapse.
- `roll_fleet` groups by the resulting effective threshold, preserving the existing ascending
  `BTreeMap` order. A matching `extra_die_unit` contributes one additional die to the first
  matching unit only; two units of that type still get one additional die total.
- A current `munitions_round` replaces only missed positions from each of that player's combat
  batches via `Dice::reroll`. The replacement has its own `munitions:<player>` reason, while
  the caller's original batch remains in history.
- No card, faction, law, or leader sets these markers yet. In particular, no unavailable action
  card is made playable by this change.
