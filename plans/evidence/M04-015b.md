## Implementation

- Added SourceTraceStates and parse_source_trace_states.
- Intake first applies the existing pinned header/choice/dice parser, then accepts exactly two source public-state records: one before and one after the bounded run.
- It validates required state-schema fields, scalar/container types, source seat order, and public player ordering against the trace header. The JSON snapshots are retained verbatim, avoiding accidental coercion or invention of hidden state.
- The all-corpus test validates snapshot boundaries for every retained trace from all four source scenarios and 25 seeds each.

## Tests

1. Valid minimal input retains initial/final state snapshots and the checked choice sequence.
2. A state seating order that differs from the pinned header is rejected at its source line.
3. Missing or additional state snapshots are rejected.
4. All 100 retained corpus traces have exactly two valid public-state boundaries.
