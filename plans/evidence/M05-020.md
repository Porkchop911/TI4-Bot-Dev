## Tactical orchestration (game.py tactical flow)

### Optional-step order
1. Activate system (place token, set active_system)
2. Movement (load cargo, move ships, gravity rift checks)
3. Space cannon offense (before combat)
4. Combat (rounds 1-50, barrage, retreat, etc.)
5. Invasion (bombardment, landing, ground combat, control)
6. Production (capacity, pricing, payment, placement)

### TACTICAL_ACTION_COMPLETE
- Emitted after production step
- active_system cleared
- pending cleared
- Turn advanced to next player

### No skipped live step
- Each step explicitly checked
- No step skipped unless no legal options
- Step order enforced by code structure

### Tactical action flow
```
_tactical_action(player_id):
    promissory.tactical_action_started(self, player_id)
    state.pending = "activate"
    _emit("TACTICAL_ACTION", player=player_id)
    # Player activates system
    # Player moves ships
    # Space cannon offense
    # Combat
    # Invasion
    # Production
    _finish_tactical_action(player_id):
        fleet.enforce_capacity_everywhere(self, player_id)
        if det: exploration.explore_frontier(...)
        combat.space_cannon_offense(...)
        combat.resolve(...)
        technology.cleanup_blockaded_factories(...)
        invasion.resolve(...)
        production.resolve(...)
        for other: fleet.enforce(other, ...), fleet.enforce_capacity(other, ...)
        _emit("TACTICAL_ACTION_COMPLETE", player=player_id)
        state.active_system = None, pending = None
        _advance_turn()
```
