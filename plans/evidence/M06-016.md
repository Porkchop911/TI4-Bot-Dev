## Blocker

The generic reaction package cannot be implemented without violating the timing dependency:

- The oracle's reaction slots register `Ability` values with a typed `Event`, `Relation`,
  `Frequency`, and `Resolver`. Their behaviour depends on WHEN/AFTER ordering, cancellation,
  round-robin pass/reoffer, nested emission, and frequency scopes.
- Rust has none of those modules. `Game` stores `Vec<String>` event labels and has no resolver;
  `lib.rs` has no `timing` or `reactions` module.
- Implementing a second reaction mechanism over string events would duplicate M03-008 through
  M03-012, create incompatible timing semantics, and let unavailable cards become apparently
  playable. That is prohibited by the migration rules.

M03-008 (typed event model) has no dependency on the separately blocked legacy-entropy work
(M03-007), so it is the next safe predecessor. M03-009 through M03-012 must then establish the
ability registry and resolver before this package resumes.
