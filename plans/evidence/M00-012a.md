## Warmup protocol

### Procedure
1. Run 100 iterations of the benchmark workload as warmup.
2. Discard warmup measurements.
3. Begin measurement after warmup completes.

### Rationale
- JIT/compiler warmup (Python's import caching, Rust's code cache)
- CPU frequency scaling stabilization
- Memory allocator warmup
- GC warmup (for any Python reference code)

### Warmup threshold (alternative)
- Warm until 3 consecutive iterations have <1% variance in wall time.
- Maximum warmup: 200 iterations.
