## Referential validation (cross-reference checks)

### Validation targets
| Source | Target | Field | Known gaps |
|---|---|---|---|
| Factions | Units | `faction` | Some TE units reference non-existent factions |
| Factions | Leaders | `leaders` | Some leaders removed in errata |
| Factions | Technologies | `factionTech` / `startingTech` | Some techs dropped in expansions |
| Units | Systems | `homeSystem` | Some systems purged (Silver Flame) |
| Systems | Planets | `planets` | Some planets removed in expansions |
| Decks | Cards | `deck` | Some cards removed from decks |
| Leaders | Units | `units` | Some units replaced by TE versions |
| Technologies | Abilities | `abilities` | Some abilities removed in errata |

### Expected gaps (allowlisted)
- `homebrewReplacesID`: Thunder's Edge units that replace base units
- `source_suffixes`: `-te` / `_te` suffixed IDs fall back to base records
- `dropped_fields`: AsyncTI4 dropped image/reference fields (not relevant to rules)
- `untagged`: 237 records with no source tag (treated as "base")

### Validation procedure
1. Load all categories
2. For each faction: validate `homeSystem`, `homePlanets`, `units`, `leaders`, `promissoryNotes`, `factionTech`, `startingTech`
3. For each unit: validate `baseType`, `source`, `faction`, `upgradesToUnitId`
4. For each system: validate `planets`
5. For each planet: validate `resources`, `influence`
6. For each leader: validate `faction`, `units`
7. For each technology: validate `source`, `abilities`
8. For each deck: validate `cards` reference valid card ids
9. For each objective: validate `type`, `source`
10. Report all gaps (not errors — allowlisted)
