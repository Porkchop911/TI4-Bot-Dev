## Bootstrap procedure for frontier reviewer

### Step 1: Clone repository
```bash
git clone https://github.com/<org>/ti4-engine-rs.git
cd ti4-engine-rs
```

### Step 2: Install Rust toolchain
```bash
rustup toolchain install 1.85.0
rustup component add rustfmt clippy rustc-dev llvm-tools-preview
cargo install cargo-audit cargo-deny cargo-llvm-cov cargo-mutants
```

### Step 3: Copy fixtures (if oracle available)
```bash
python tools/copy_fixtures.py
# Or set TI4_FIXTURES_DIR for CI mode
```

### Step 4: Build workspace
```bash
cargo build --workspace --all-targets
```

### Step 5: Run all checks
```bash
# Formatting
cargo fmt --all -- --check

# Linting
cargo clippy --workspace --all-targets --all-features -- -D warnings

# Tests
cargo test --workspace --all-targets --all-features

# Docs
cargo doc --workspace --no-deps --document-private-items

# Security
cargo audit
cargo deny check licenses
cargo deny check provenance
cargo deny check duplicates
```

### Step 6: Verify version command
```bash
ti4 --version
# Should output all 6 fields
```
