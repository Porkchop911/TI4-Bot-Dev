## The claim that mattered, checked against a real model

§6.2 defines "actor frozen" unusually explicitly, and says why: *"'Actor frozen' includes the shared
`W2`, biases, all policy input rows, readouts, residuals, and embeddings; otherwise a nominal critic
warm-up would silently destroy imitation."*

Exactly two things train — the `critic-state:` input rows, which no policy vector gathers, and the
value head, which no policy readout touches. Both are disjoint from the policy path, which is what
makes the guarantee available at all.

It is checked **bit for bit**, not within a tolerance: the design claim is that the policy
computation reads none of the changed parameters, and that claim predicts identical bits. Up to now
it had only ever been demonstrated on a fixture; this run is the first against a model that had
actually been trained, and it holds.

Both halves are load-bearing together. Without the movement figure, a warm-up that trained nothing
would satisfy "logits unchanged" perfectly.

## Where the guarantee actually lives

Recorded because a probe contradicted the obvious reading. The `freeze!` calls in `open_critic_only`
are **not** the mechanism: unfreezing `W2` and rerunning the end-to-end test changes nothing, because
`RowAdam` writes no update there either way. The falsification that *does* fail the test is letting
an update reach the shared trunk.

That matters for anyone maintaining this. `RowAdam` is confined to the critic rows by construction
rather than by masking a dense gradient, and masking would fail quietly: Adam's weight decay adds
`wd × param` to the gradient, so every policy row would still decay even with its gradient zeroed,
and the logits would drift a little each step. A reader who believed the freezing were the mechanism
would "simplify" `RowAdam` into a masked dense Adam and reintroduce exactly that.

## Explained variance rather than MSE

MSE is not comparable across corpora — a critic predicting a constant scores well when returns barely
vary. Explained variance is 0 for the predict-the-mean baseline and negative for anything worse,
which is the comparison §6.2's threshold means. A degenerate split, where every return is identical,
reports NaN rather than 1.0, so a constant critic cannot clear the threshold having learned nothing.
