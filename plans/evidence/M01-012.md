### Branch naming convention
- **Main:** `main` (integration branch)
- **Milestone branches:** `m01`, `m02`, etc. (for implementation milestones)
- **Package branches:** `m01-001`, `m01-002`, etc. (for atomic work packages)
- **Feature branches:** `feature/<name>` (for larger features)

### Package/evidence rules
1. Each work package gets its own branch from `main`
2. Package plan in `plans/<PACKAGE-ID>.md`
3. Evidence in `plans/evidence/<PACKAGE-ID>.md`
4. Evidence files must be committed with package
5. EXECUTION_STATE.md updated before each package
6. Index.md updated when new milestones/packages created

### Discoverability
- `AGENTS.md` at root: agent instructions, execution rules
- `plans/INDEX.md` at root: all milestones and their outcomes
- `plans/SCOPED_PERMISSIONS.md` at root: permission classes
- `plans/EXECUTION_STATE.md` at root: current position
- `plans/MASTER_PLAN.md` at root: full milestone chain
- `plans/PI_WORK_PACKAGE_STANDARD.md` at root: work package template
