# VP-only pilot against frozen opponents — 2026-09-16

Astra's fourth measurement: train the matchup promotion asks about, with a transparent objective.

## The run

`scripts/vp_pilot.psd1`, launched through `scripts/ppo_train.ps1` so `launch.json` records the
config, commit `cfe0323`, `dirty: false`, and every resolved argument -- the provenance that was
missing from the overnight run.

- Learner starts from `checkpoint-212544`; five frozen copies of the same bundle play every other
  seat at temperature 0.001.
- One faction learns per rotation, so each seed block trains all six exactly once.
- Reward: `--vp-weight 1`, with objective, secret, r1 bonus, r1 shaping, clearance, fleet, tech,
  diversity, both hoard penalties, waste, Styx and both Fracture bonuses all explicitly zero.
- 300 updates, ~20.5s each, about 1.7 hours. Empty stderr. Final bundle `checkpoint-10456`,
  schema 10, reloads identical.

Cost per update against six-seat self-play on the same bundle: 34k decisions against 237k, rollout
~19s against 25.3s, optimise ~1.4s against 8.5s, 40 Adam steps against 232, process memory 3.9 GB
against ~22 GB. One learner seat is a sixth of the trainable data: 300 updates here is a probe.

## What it shows

- **VP moved in the right direction**: +0.26 paired against its own start, +0.17 against the
  champion, with margin better by about 0.14 in both. The intervals overlap the nulls, so on 20
  blocks this is suggestive, not established.
- **Wasted activations exploded: 9.9% to 68.9%.** With no waste penalty, roughly seven games in ten
  contain a pointless activation, and clearance fell from 93.9% to 89.3%. The control did what a
  control is for: it showed what a pure VP objective does when nothing objects to waste.
- Astra's arithmetic on the old run stands -- waste 10 against VP 1.1 was about nine VP per event,
  far too punitive -- but zero is clearly wrong too.

## What to run next

A small waste penalty against VP 1 (0.25 to 1.0), same seeds, same budget, to find whether the VP
gain survives when waste is discouraged rather than either free or catastrophic. Then repeat the
promising arm with an independent training seed before believing it, and keep a held-out block set
for a final check after selection.
