## Tests to add

1. A carrier receives a named lift-shortage component and wins an otherwise equal production
   choice when public stranded troops need transport.
2. The same choice remains blind under `choose`, proving the observation path is additive rather
   than silently changing all window calls.

## Implementation

- `choose_seeing` now gives `produce` options the existing value-per-resource components plus a
  public `lift_shortage` component when more than two friendly ground forces are stranded.
- `valuation::stranded_troops` now traverses every public board system, not only systems with a
  friendly unit in space. Planet-only troops are therefore counted correctly.
- Existing content-based casualty, sustain, and retreat scoring remains in the shared dispatcher;
  this package does not replace working combat judgments with untested board heuristics.
