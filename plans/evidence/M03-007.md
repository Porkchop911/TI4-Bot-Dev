## Legacy entropy translator

### Purpose
- Convert legacy Python-seeded scenarios to explicit entropy + decisions
- Enable 100 fixtures to reproduce identically in Rust
- Decouple Rust from Python's RNG implementation

### Translation process
1. Run Python scenario with seed
2. Record all entropy events (dice rolls, deck shuffles, random calls)
3. Record all decisions (option ids chosen)
4. Store as NDJSON with explicit entropy stream
5. Rust replays by consuming entropy stream instead of using its own RNG

### Entropy stream format (NDJSON)
```json
{"type":"dice_roll","stream":"dice_rolls","value":42,"target":6}
{"type":"deck_shuffle","stream":"deck_shuffles","deck":"action_card_deck","cards":["action_1","action_2",...]}
{"type":"random_choice","stream":"random_decisions","value":0.73,"options":3}
{"type":"decision","player":"player_1","option":"option_1","prompt":"Choose action"}
```
