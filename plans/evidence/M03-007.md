# M03-007 — Legacy entropy translator

## Split record

The original package bundled a trace parser, a 100-fixture capture corpus, and native semantic
replay. That exceeds the atomic-package limit and cannot be represented honestly as one completed
item. It is split without changing its acceptance criterion:

| Child | Scope | Status |
|---|---|---|
| M03-007a | Strict parsing of existing bounded oracle NDJSON into explicit selected decisions and dice entropy. | Complete |
| M03-007b | Versioned, checksummed 100-trace capture corpus from the pinned oracle. | Complete |
| M03-007c | Native replay consumes the captured inputs and proves the same canonical Rust projection. | Blocked on generic-game parity |

The parent package remains incomplete until all children pass. In particular, no current code
claims that a Python-seeded scenario is replayable by the Rust game.

## Original acceptance criterion preserved

Convert legacy Python-seeded scenarios to explicit entropy plus decisions, store 100 reproducible
fixtures, and have Rust consume those explicit streams rather than Python RNG behavior.

**In progress — M03-007b is complete; M03-007c remains blocked on generic-game parity.**
