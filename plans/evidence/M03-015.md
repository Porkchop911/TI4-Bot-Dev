## Timing property/fuzz suite

### Property tests (proptest)
| Property | Description | Test |
|---|---|---|
| `terminate` | Generated registries always terminate | `proptest! { ... }` |
| `at_most_allowed_frequency` | Ability resolves at most allowed frequency | `assert!(count <= max)` |
| `never_ineligible` | No ineligible ability executes | `assert!(ability.is_eligible())` |
| `no_duplicate_resolution` | Same ability not resolved twice in window | `assert!(resolved_here.len() == resolved_here.len())` |
| `deterministic_trace` | Same input → same trace | `assert_eq!(trace1, trace2)` |
| `pass_terminates` | Pass/reoffer always terminates | `assert!(passes <= max_passes)` |

### Fuzz tests
| Fuzz input | Generation method | Validation |
|---|---|---|
| `random_abilities` | Generate random ability list | No crash, no panic |
| `random_events` | Generate random event sequences | No illegal state |
| `random_player_orders` | Permute player order | Deterministic result |
| `random_frequencies` | Mix frequency types | Correct scope keys |
| `random_cancellation` | Cancel at various depths | No double-cancellation |

### Generated registries termination
- Registry size bounded (max 1000 abilities)
- Event depth bounded (max 100 levels)
- Pass count bounded (max 100 passes)
- All bounded → guaranteed termination

### Frequency validation
- Generate random ability sets with mixed frequencies
- Verify each ability resolves at most its frequency allows
- Verify scope keys match expected values
