# M04-015c1 — Deterministic public-state comparator

## Active package specification

| Field | Value |
|---|---|
| Parent / dependencies | M04-015a native projection and M04-015b checked source snapshots. |
| Objective | Compare a native state projection against a checked source public-state snapshot and report the first deterministic field-level difference. |
| Oracle source | tools/oracle_exporter/projections/state.py::state_projection. |
| Writable paths | crates/ti4-legacy/src/projection.rs, plans/evidence/M04-015.md, this evidence file, and plans/EXECUTION_STATE.md. |
| Permission | P0 source inspection; P1 repository code/tests/evidence/local Git. No network, P2 generation, ports, destructive action, or external-state change. |
| Input / output | Native GameState and a checked source JSON snapshot; either equality or the first stable path with expected and actual JSON values. |
| Compatibility | Exact comparison of the executable public-state schema, including list order. No source scenario is constructed and no parity result is claimed by this utility alone. |
| Non-goals | Tolerant comparison, private fields, state import, replay, entropy injection, event comparison, or accepting an aggregate-only match. |

## Implementation

- Added StateProjectionDifference and first_state_projection_difference.
- The comparator recurses through ordered JSON maps and sequence indices. It treats sequence order as semantically significant and reports missing/extra fields explicitly.
- A mismatch exposes a stable JSONPath-like path together with source expected and native actual values, making later differential evidence decision-boundary auditable instead of a single opaque boolean.

## Tests

1. A nested player victory-point mismatch reports the expected path and both values.
2. A source-only field reports as missing from the native projection.
3. The existing native public-schema/redaction and byte-stability tests remain green.
