### Phase transitions
| From | To | Trigger |
|---|---|---|
| STRATEGY | ACTION | Draft complete, strategy phase ended |
| ACTION | STATUS | All players passed |
| STATUS | AGENDA | Custodians removed, not finished |
| STATUS | STRATEGY | Custodians not removed (next round) |
| AGENDA | STRATEGY | Agenda resolved (next round) |

| Phase | Legal commands |
|---|---|
| STRATEGY | `pick_strategy_card(card_id)` |
| ACTION | `take_action(action_id)`, `activate(system_id)`, `move(origin, target)`, `pass`, `end_turn` |
| STATUS | (automated) |
| AGENDA | (automated) |

### Phase-specific state
| Phase | active_player | speaker | pending |
|---|---|---|---|
| STRATEGY | None | speaker | None |
| ACTION | current player | None | None/activate/move |
| STATUS | None | None | None |
| AGENDA | None | None | None |

### Explicit legal commands
- Each phase transition guarded by `match self.state.phase`
- Illegal phase → error (not silent skip)
- Phase must be set before transition
