# M00-012 — Executable benchmark protocol reconciliation

## Package specification

- **Milestone/package:** M00-012; dependency M00-001 environment record.
- **Objective:** Replace contradictory benchmark planning drafts with one fixed protocol before
  M00-013 takes any performance measurement.
- **Permission class:** P1 documentation only. No oracle execution, network access, benchmark
  process, power-plan/affinity mutation, or generated benchmark artifact.
- **Inputs/outputs:** M00-001 host record and master-plan performance gates in; fixed warmup,
  sampling, affinity, schema, and variance rules out.
- **Compatibility class:** process contract. No performance/parity claim is made.

## Reconciliation

The prior drafts offered both fixed and open-ended warmups, mandated core zero despite topology and
permission differences, proposed randomized order without a reproducible seed, and allowed a
timestamped report without stating what is excluded from equality. The revised five child documents
fix those choices and require raw samples. They also prohibit automatic host-configuration changes.
