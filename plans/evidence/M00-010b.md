## Dice entropy capture

### Roll structure (from engine/dice.py)
```json
{
  "type": "dice_roll",
  "reason": str,
  "faces": [int],
  "hits_on": int | null,
  "rerolled": [int]
}
```

### Capture points
1. **Combat rolls**: `Dice.roll(count, reason="combat", hits_on=8)`
2. **PDS rolls**: `Dice.roll(count, reason="pds", hits_on=8)`
3. **Ability rolls**: `Dice.roll(count, reason="ability_name", hits_on=N)`
4. **Rerolls**: `Dice.reroll(roll, positions, reason="reroll_reason")`

### Verification
- Every roll is recorded in `Dice.history`
- Repeated export of the same game produces identical dice rolls
- Reroll positions are explicitly captured
