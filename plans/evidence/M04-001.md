### Distance algorithm
```
distance(self, other) = (|dq| + |dr| + |dq + dr|) / 2
where dq = self.q - other.q, dr = self.r - other.r
```
- Inlined (not via s property) for performance
- Verified against trace-equality baseline
- Called 139,000 times per round-4 six-player game

### Axial directions (clockwise from east)

DIRECTIONS = [(1,0), (1,-1), (0,-1), (-1,0), (-1,1), (0,1)]

### Deterministic serialization
- `Hex(q, r)` → `"q:r"` (sorted by q, then r)
- `ring(n)` → clockwise from south-west corner
- `spiral(n)` → ring 0, ring 1, ..., ring n

### Property tests
- `distance(a, b) == distance(b, a)` (symmetry)
- `distance(a, a) == 0` (reflexivity)
- `distance(a, c) <= distance(a, b) + distance(b, c)` (triangle inequality)
- `ring(0) == [Hex(0, 0)]` (trivial ring)
- `len(ring(n)) == 6n` for n > 0 (ring size)
- `spiral(n) == concat(ring(0), ring(1), ..., ring(n))` (spiral composition)
