- **Inputs/outputs:** an oracle `Choice` in; a deterministic JSON-ready choice object out.

## Implementation

- Added `tools/oracle_exporter/projections/choice.py` and exported `choice_projection`.
- `choice_projection` emits `type`, player, prompt, and options in oracle-provided order.
  Each option contains id, kind, label, and a recursively normalized payload.
- Payloads accept JSON scalars, finite floats, sequences, and string-keyed maps. Map keys are
  sorted; sequences retain their order. Non-finite floats, non-string keys, and unsupported
  Python objects raise explicit errors rather than becoming lossy strings or non-standard JSON.
- Focused tests cover option-order preservation, nested payload key canonicalization, byte-identical
  compact JSON, and failure on an unsupported payload object.
