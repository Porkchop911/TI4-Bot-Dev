### Choice projection function

```python
def choice_to_ndjson(choice: Choice) -> dict:
    """Convert Choice to NDJSON projection (M00-007c schema)."""
    return {
        "type": "choice",
        "player": choice.player,
        "prompt": choice.prompt,
        "options": [
            {
                "id": opt.id,
                "kind": opt.kind,
                "label": opt.label,
                "payload": opt.payload,
            }
            for opt in choice.options
        ],
    }
```
