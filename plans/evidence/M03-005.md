### Versioned append-only records
- Records are immutable (frozen dataclass)
- Log is append-only (no mutation of existing records)
- Version: schema_version embedded in serialization
- Canonical serialization: JSON with deterministic field order

### Replay cursor
- `as_script(player)` returns chosen option ids in order
- Replay cursor advances through script sequentially
- Error: script exhausted but more choices needed → replay failure
- Error: option id not found in current state → illegal replay
