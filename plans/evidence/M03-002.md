## Choice validation (from `engine/choice.py`)

### validate function
```python
def validate(choice: Choice, option: Option) -> Option:
    """Reject any answer that was not among the offered options."""
    if option.id not in choice.ids:
        raise IllegalChoice(
            f"{choice.player} chose {option.id!r}, "
            f"which was not offered: {choice.ids}"
        )
    return option
```

### IllegalChoice exception
- Raised when a decider returns an option not on the choice
- Boundary that keeps LLM/buggy bots from inventing moves
- Contains: player, chosen id, offered ids

### Validation rules
1. **Only offered options can execute**: `validate(choice, option)` must pass
2. **Altered payload rejected**: option.payload must match what was offered
3. **Duplicate ambiguity rejected**: identical option ids in same choice = error

### Table.ask validation
- `Table.ask(choice)` validates the answer before recording
- `IllegalChoice` propagates through the stack
- Decider not seated → uses default (FirstOption)
