## Decider interface (from `engine/choice.py`)

### Decider protocol
```python
class Decider(Protocol):
    """Anything that can answer a Choice."""
    def choose(self, choice: Choice) -> Option: ...
```

### Seated deciders
| Decider | Purpose | Behavior |
|---|---|---|
| `FirstOption` | Tests, default | Always take first option |
| `AlwaysDecline` | Smoke tests | Decline if legal, else first |
| `Scripted` | Conformance tests | Fixed sequence of option ids |
| `SeededRandom` | Smoke runs | Uniform random from seed |

### FirstOption
- `choose(choice) -> choice.options[0]`
- Deterministic; default in tests
- No decline logic

### AlwaysDecline
- `choose(choice) -> option` where `option.kind == "decline"` if present, else `options[0]`
- Used for smoke tests that assert every game terminates

### Scripted
- `__init__(option_ids, fallback=None)`
- `choose(choice) -> option` from queue
- Raises `IllegalChoice` if wanted option not offered
- Falls back to `FirstOption` when queue exhausted

### SeededRandom
- `__init__(seed)`
- `choose(choice) -> rng.choice(choice.options)`
- Uniform random over legal options
- Not a bot — drives smoke runs

### Bounded interface
- Decider receives only `Choice` and authorized `view/context`
- No access to full `GameState`
- Decider cannot invent options (validation prevents this)
