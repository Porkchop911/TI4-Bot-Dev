## Implementation

### `ResumeState` struct
Holds all state needed to resume a training run:
- `champion`: BTreeMap of faction → Profile (from checkpoint.accepted)
- `learner`: BTreeMap of faction → Profile (from checkpoint.profiles, falls back to accepted)
- `history`: Vec of training history entries
- `telemetry`: Vec of telemetry rows
- `archive`: Historical artifacts
- `start_update`: Max update index from history
- `eval_every`: Evaluation interval (oracle default: 10)
- `validation_seeds`: 32 seeds at `seed + 9_000_000` (oracle default)
- `confirmation_seeds`: 32 seeds at `seed + 14_000_000` (oracle default)
- `checkpoint_path`: Path to the checkpoint file

### `Archive::resume()`
Loads a checkpoint and extracts training state:
1. Loads checkpoint from disk (validates schema, checksum)
2. Extracts champion from `accepted` (hard error if empty)
3. Extracts learner from `profiles`, falling back to `accepted`
4. Validates champion/learner factions match
5. Computes `start_update` from max update in history
6. Extracts seed ranges from checkpoint arguments or uses oracle defaults
7. Returns `ResumeState`

### New error variant
- `CheckpointError::ProfileValidation(String)`: For profile validation errors (empty champion, faction mismatch)
