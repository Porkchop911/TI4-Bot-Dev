## Choice projection (from engine/choice.py)

### Option
```python
@dataclass(frozen=True)
class Option:
    """One legal thing an actor may pick.
    
    id must be stable for a given game state so decision logs replay faithfully.
    """
    id: str
    kind: str
    label: str = ""
    payload: dict = field(default_factory=dict, compare=False)
```

### Choice
```python
@dataclass(frozen=True)
class Choice:
    """A decision point handed to exactly one actor."""
    player: str
    prompt: str
    options: tuple[Option, ...]
    
    def option(self, option_id: str) -> Option | None: ...
    @property
    def ids(self) -> tuple[str, ...]: ...
```

### Key invariants
- Every decision is: "engine enumerates legal options, actor picks one"
- `id` must be stable for a given game state
- `kind` categorizes the decision type
- `label` is a human-readable description
- `payload` carries decision-specific data
- `DECLINE = Option(id="decline", kind="decline", label="Decline")` — standard decline option
- `distinct_units()` deduplicates interchangeable units by (type_id, sustained_damage)
- `first_of_each()` preserves original order, keeps first index for stable IDs
