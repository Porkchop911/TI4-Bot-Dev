## Ground combat (from `engine/invasion.py`)

### Rounds
- Ground combat resolves per planet
- Attacker rolls ground force dice
- Defender rolls planetary defense dice
- Hits assigned to opposing forces

### Modifiers
| Modifier | Effect |
|---|---|
| Planet resources | Bonus dice for defender |
| Planet influence | Bonus dice for defender |
| Structures | PDS adds space cannon dice |
| Technology | Tech bonuses (e.g., siege) |

### Casualties
- Attacker casualties: ground forces destroyed
- Defender casualties: planetary defense units destroyed
- Each hit destroys one unit

### Control transition
- If attacker has more units after combat → attacker controls planet
- If defender has more units → defender retains control
- If equal → no change (current controller retains)
- Planet control recorded in GameState

### Termination
- Combat ends when one side has no units
- Or when both sides agree to stop
- Excess casualties counted
