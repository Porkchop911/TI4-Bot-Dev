## Entropy capture design

### Entropy sources in the Python engine

| Source | Module | Description |
|---|---|---|
| Dice rolls | `engine/dice.py` | Seeded ten-sided roller with full history |
| Deck shuffles | `engine/opening.py`, `engine/game.py` | Strategy card draft, action card distribution |
| Random decisions | `engine/choice.py`, `engine/bots.py` | Bot sampling, ability resolution |
| Game seed | `engine/game.py` | Initial game seed for reproducibility |

### Dice entropy (engine/dice.py)
```python
@dataclass(frozen=True)
class Roll:
    reason: str
    faces: tuple[int, ...]
    hits_on: int | None = None
    rerolled: frozenset[int] = frozenset()

class Dice:
    seed: int = 0
    sides: int = 10
    history: list[Roll] = field(default_factory=list)
    _rng: random.Random  # Seeded from seed
    
    def roll(self, count: int = 1, reason: str = "", hits_on: int | None = None) -> Roll
    def reroll(self, roll: Roll, positions: Iterable[int], reason: str | None = None) -> Roll
```

### Deck entropy (engine/opening.py, engine/game.py)
- Strategy cards: `strategy_card_setup()` selects from `strategy_card_sets`
- Action cards: Distributed via `opening` module
- Deck shuffles: `random.shuffle()` on card lists

### Random decision entropy (engine/choice.py, engine/bots.py)
- `random.Random` seeded per-game
- Bot sampling: `_sample()` draws from option list
- Ability resolution: `first_of_each()` preserves order

### Entropy capture mechanism
```python
class EntropyCapture:
    """Captures all random decisions for replay."""
    
    def __init__(self, game_seed: int):
        self.game_seed = game_seed
        self.dice_rolls: list[dict] = []
        self.deck_shuffles: list[dict] = []
        self.random_calls: list[dict] = []
    
    def capture_roll(self, roll: Roll, reason: str) -> dict:
        return {
            "type": "dice_roll",
            "reason": reason,
            "faces": list(roll.faces),
            "hits_on": roll.hits_on,
            "rerolled": list(roll.rerolled),
        }
    
    def capture_shuffle(self, deck_id: str, cards: list[str], seed: int) -> dict:
        return {
            "type": "deck_shuffle",
            "deck_id": deck_id,
            "cards": cards,
            "seed": seed,
        }
    
    def capture_random(self, func: str, args: tuple, result) -> dict:
        return {
            "type": "random_call",
            "func": func,
            "args": args,
            "result": result,
        }
```

### Replay mechanism
```python
class EntropyReplay:
    """Replays a game using captured entropy."""
    
    def __init__(self, captured: list[dict]):
        self.captured = captured
        self.index = 0
    
    def next_roll(self) -> Roll:
        entry = self.captured[self.index]
        self.index += 1
        return Roll(**entry)
    
    def next_shuffle(self) -> list[str]:
        entry = self.captured[self.index]
        self.index += 1
        return entry["cards"]
    
    def next_random(self) -> Any:
        entry = self.captured[self.index]
        self.index += 1
        return entry["result"]
```
