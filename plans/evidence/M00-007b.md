## View projection (from engine/views.py)

### Redaction rules
- `PRIVATE_SEQUENCES = ("action_cards", "secret_objectives")` — per-player fields nobody else may read
- `HIDDEN = "?"` — marker for private card identities
- Public counts survive; identities do not
- `promissory_notes` is NOT in PRIVATE_SEQUENCES (public information)
- `lrr 61.17` makes an unscored secret objective hidden until scored

### view_for(state, viewer)
```python
def view_for(state: GameState, viewer: str) -> GameState:
    """The game as one player is entitled to see it.
    
    Their own state is untouched; the board is shared;
    only other players' private holdings change.
    """
    return replace(
        state,
        players=tuple(
            p if p.id == viewer else redact_player(p) for p in state.players
        ),
    )
```

### redact_player(player)
```python
def redact_player(player: Player) -> Player:
    changes = {}
    for field in PRIVATE_SEQUENCES:
        held = getattr(player, field)
        if held:
            changes[field] = tuple(HIDDEN for _ in held)
    return replace(player, **changes) if changes else player
```

### GameView
```python
class GameView:
    """A game whose state is redacted for one player.
    
    Everything except state is delegated to the real game,
    so a bot can still ask to enumerate legal options, emit events or roll dice.
    """
    __slots__ = ("_game", "_viewer", "_cached_from", "_cached")
```
