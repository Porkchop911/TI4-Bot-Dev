# M00-012c — Affinity and worker policy

The runner records the Windows processor group, logical-processor count, current process affinity,
and requested worker count. It does not change affinity or priority automatically: core numbering,
processor groups, and permission vary across Windows hosts. A run is comparable only when the two
implementations report the same host fingerprint and affinity policy.

Single-thread benchmarks use one worker. Fixed-throughput benchmarks use 12 workers only when the
host has at least 12 logical processors in the relevant processor group; otherwise they are marked
`unsupported_host`, not silently reduced. GPU/training workloads must additionally record device
name, driver, and memory. Operators must leave no known competing benchmark/simulation process
running; that condition is recorded as an operator assertion, not inferred.

**Status:** superseded draft replaced by fixed M00-012 protocol; no benchmark measurement claimed.
