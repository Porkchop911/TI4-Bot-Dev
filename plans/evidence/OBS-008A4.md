## Result

1. **Engine.** Every landing (`commit|…`) option now carries `Preview::certain` with one
   `Quantity::GroundForcesOnPlanet` delta: the invader's own ground-force count already on that
   planet (`state.system_state(system).on_planet_of(planet, invader).len()`, read once per choice,
   not per option), to one more. This states only the immediate placement LRR 49.2 performs — it
   claims nothing about the ground combat, casualties, or control transfer that may follow, the
   same boundary `OBS-008c2b` already drew for placement's fleet/capacity facts. The "commit no
   more" decline option keeps no preview. `commit_options` gained `state`/`invader`/`system`
   parameters; both call sites (`commit_ground_forces`, `InvasionWindow::landing_options`) updated.
2. **Own count only.** The before value counts only the invader's own ground forces; an opposing
   seat's presence on the same planet does not enter it — the actor-owned framing representation
   rule 5 requires.
3. **Policy.** `tactical_decision_features`'s subtype guard now also matches
   `commit_ground_forces`; a `GroundForcesOnPlanet -> "ground-forces"` arm joins the existing
   delta-name match, emitting `tactical:ground-forces-{before,after,change}` under
   `tactical:preview-known`. No new family, no vocabulary bump.
4. **Boundaries.** Previews are `#[serde(skip)]`; no option ID, label, payload, legal set, replay
   script, or V1/V2 decision hash moves. No `DecisionContext` field is added or changed. Landing
   legality, `landable`, and `landable_planets` are untouched.

## Focused evidence

- `invasion.rs::obs008a4_commit_options_preview_the_invaders_own_ground_count_rising_by_one`: a
  two-planet arena with two invader infantry in space and an opposing seat's infantry already on
  one planet. Every landing option previews `GroundForcesOnPlanet` `0 -> 1` (the opponent's
  presence does not enter the invader's own count); the decline option has no preview. After the
  first landing actually resolves, the next choice's option for the same planet previews `1 -> 2`.
- `features.rs::obs008a4_commit_options_carry_the_invaders_own_ground_count_rising_by_one`: a
  `commit_ground_forces` choice with a previewed landing and a bare decline option.
  `tactical:subtype:commit_ground_forces`, `tactical:option-count` (2), and exact
  `tactical:ground-forces-{after,change}` (1 / 1, with a genuine-zero `before` a dropped sparse
  entry) reach the policy; the decline option carries the subtype but no consequence fact; the
  facts survive `mlp_option_features` and `projection::admits`.
