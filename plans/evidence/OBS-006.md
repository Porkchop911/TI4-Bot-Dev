## Result

`add_system_features` (the pre-existing per-target board-fact function every board-targeting option
kind already calls) gains two fact groups, both already-registered families (`target`, `production`,
`placement`, `origin`, `option-system` — no vocabulary/projection registry change needed):

1. **`{prefix}:present-slot-{0..4}`** — 1.0 iff that OBS-005 opponent slot's seat holds any unit or
   planet control in the target system. Closes representation rule 4's "relevant relationships":
   the existing `rival-seats`/`enemy-ships` facts were aggregate-only and could not say *which kind*
   of opponent was present.
2. **`{prefix}:objective-progress-gain`** / **`{prefix}:objective-newly-satisfied`** — the exact
   counterfactual delta from `revealed_objective_progress_gaining(player, uncontrolled_planets)`
   against the current position, clipped exactly as `objective_facts` already clips. Closes the
   row's "objective-location": the engine's own "what if I also controlled these planets" helper
   existed and was called from nowhere.

## Focused evidence

- `obs006_present_slot_facts_are_relationship_relative_not_identity_relative`: the same opponent
  presence in a target system, attached to a different concrete seat holding the identical
  relationship to the actor, emits the identical `target:present-slot-0` fact.
- `obs006_objective_progress_gain_reflects_the_counterfactual_not_the_current_position`: a target
  system holding an uncontrolled, non-homeworld planet counting towards a revealed `expand_borders`
  ("control 6 planets in non-home systems") emits a positive `target:objective-progress-gain`, even
  though the current, ungained position does not satisfy it.
  - **Fixture trap found and fixed while writing this test:** `plain_hub()`'s low-numbered ring
    systems are every faction's homeworld tile, which `expand_borders`'s own `non_home_count`
    predicate excludes by construction — the first version of this test picked such a tile (Moll
    Primus) and always measured zero gain. Fixed by building the hub around tile 19 (an ordinary,
    single-planet, non-home system) explicitly rather than assuming the first ring tile qualifies.
