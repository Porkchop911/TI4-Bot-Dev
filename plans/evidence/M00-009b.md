# M00-009b — Executable state projection

## Package specification

- **Milestone/package:** M00-009b, state projection implementation; dependency M00-007a.
- **Objective:** Add a read-only, deterministic, JSON-ready projection of the Python oracle's
  current public `GameState`.
- **Oracle sources inspected read-only:** `engine/state.py`, `engine/game.py`, `engine/units.py`,
  and `engine/timing.py` at `37061c511a4780d4c0719e0342533a498cd4b457`.
- **Oracle test reference:** `tests/test_game.py`; the local focused test exercises the same
  `start_game` setup seam with a bounded synthetic board state.
- **Permission class:** P0 oracle inspection; P1 writes limited to
  `tools/oracle_exporter/`, `tools/test_oracle_state_projection.py`, this evidence file, and
  `plans/EXECUTION_STATE.md`. No network or external state; the oracle is not written.
- **Inputs/outputs:** an oracle `GameState` in, a JSON-ready `dict` with deterministic ordering
  out. This package does not create an NDJSON file or invoke a complete game.
- **Compatibility class:** semantic. The projection preserves public state and ordering; private
  action-card and secret-objective identities are represented only as counts.
- **Explicit non-goals:** CLI, NDJSON framing, views, choices, events, outcomes, errors,
  fixture corpus generation, Rust/Python comparison, and a parity claim.

## Implementation

- Added `tools/oracle_exporter/projections/state.py`, which uses no oracle import at module load
  time and canonicalizes system ids, units, token sets, maps, technology sets, and player order.
- The implementation maps the actual oracle's `turn_seq` to exported `turn`. The prior planning
  draft named obsolete fields (`GameState.turn`, player name/color, one combined token count, and
  agenda-vote fields) that do not exist at the pinned oracle commit. The executable projection
  instead exposes the current oracle's public token pools, faction, held strategy cards, board,
  and laws. This schema reconciliation must be carried through the later M00-007 specification
  correction before a full cross-engine schema can be declared exact.
- Added two focused tests: canonical ordering/redaction of a nontrivial board, and byte-identical
  compact JSON for independently initialized same-seed games.
