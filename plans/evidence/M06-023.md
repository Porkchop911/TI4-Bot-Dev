## Implementation

- Added typed exact position progress for all six remaining public objectives and all seventeen
  remaining position-based secrets. Existing legality derives from the same progress records.
- Preserved unavailable separately from factual zero for the three map-dependent public and three
  map-dependent secret families; `fc` is also unavailable at a one-player table rather than
  returning a zero threshold.
- Added typed cost-family progress for all ten bought objectives. `have` is the greatest integer
  `k <= target` accepted by the existing exact affordability path for the same cost scaled to `k`.
- Preserved distinct-system, distinct-neighbour, distinct-home-reach, wormhole-kind, and rival-note
  issuer reductions. Rival faction notes map to their seated player identity when possible so a
  Support note and a faction note from the same issuer do not double count.
- Progress queries borrow immutable state and never invoke payment mutation.
