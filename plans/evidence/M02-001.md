### ID source mapping (from `engine/content.py`)
- `resolve_id(record_id, known)` strips `-te` / `_te` suffixes for Thunder's Edge compatibility
- `SOURCE_SUFFIXES = ("-te", "_te")` — base id fallback when suffixed id not found
- Content categories: 28 categories, 1,800 records total, 237 untagged

- Display must produce the canonical string form
