## Structured transactions (from `engine/transactions.py`)

### Offers/transfers/promises
| Type | Description | Hidden |
|---|---|---|
| Offer | Player offers to give something | Visible |
| Transfer | Player gives something to another | Visible |
| Promise | Player promises to give something | Hidden (owner) |

### Hidden ownership validated
- Promissory notes hidden from other players
- Note owner = `alias:owner` format
- Only owner can see note contents
- Other players see `HIDDEN = "?"` markers

### Transaction structure
```
Transaction {
    from: PlayerId,
    to: PlayerId,
    type: Offer | Transfer | Promise,
    commodity: Option<i32>,
    trade_good: Option<i32>,
    note: Option<PromissoryNote>,
}
```

### Transaction validation
- From player must have resources
- To player must be valid target
- Hidden ownership verified before reveal
- Transaction limits enforced (once per neighbour per turn)
