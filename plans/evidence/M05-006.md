## Atomic movement application (movement state transitions)

### Full move commits or no state changes
- Move is atomic: all or nothing
- If gravity rift destroys ship → state changes (ship destroyed, cargo lost)
- If move succeeds → state changes (ship moved, cargo carried)
- No partial commits possible

### Conservation property
- `before.total_units() == after.total_units()` (before combat)
- `before.total_tokens() == after.total_tokens()` (token conservation)
- `before.player_count == after.player_count`
- No orphan units/tokens

### State transitions
| Transition | Before | After |
|---|---|---|
| Ship moved | Ship in origin | Ship in destination |
| Ship destroyed | Ship in origin | Ship destroyed |
| Cargo loaded | Cargo in origin | Cargo in ship |
| Cargo unloaded | Cargo in ship | Cargo in destination |
| Token placed | Token in pool | Token in system |
| Token returned | Token in system | Token in pool |

### Gravity rift handling
- If ship survives: move + cargo (as normal)
- If ship destroyed: destroy ship + cargo in origin
- Cargo loss announced with system and passengers
