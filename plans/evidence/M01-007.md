## Security checks (.github/workflows/security.yml)
```yaml
name: Security
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
  schedule:
    - cron: '0 0 * * 1'  # Weekly

jobs:
  security:
    runs-on: windows-latest

    steps:
      - uses: actions/checkout@v4

      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable

      - name: Install cargo-audit
        run: cargo install cargo-audit

      - name: Run cargo-audit (vulnerability check)
        run: cargo audit --deny warnings

      - name: Install cargo-deny
        run: cargo install cargo-deny

      - name: Run cargo-deny (license check)
        run: cargo deny check licenses

      - name: Run cargo-deny (provenance check)
        run: cargo deny check provenance

      - name: Run cargo-deny (duplicate dependencies)
        run: cargo deny check duplicates
```

## cargo-deny configuration (deny.toml)
```toml
[licenses]
unlicensed = "deny"
allow = [
    "MIT",
    "Apache-2.0",
    "BSD-2-Clause",
    "BSD-3-Clause",
    "ISC",
    "Unicode-DFS-2016",
    "Unicode-3.0",
    "Zlib",
    "OpenSSL",
]
deny = [
    "GPL-2.0",
    "GPL-3.0",
    "AGPL-3.0",
]
copyleft = "deny"

[[licenses.exceptions]]
name = "ring"
use-text = true  # Allow if license is unclear

[[licenses.clarify]]
name = "ring"
expression = "MIT OR ISC OR OpenSSL"
license-files = []

[[licenses.private]]
ignore = true
```
