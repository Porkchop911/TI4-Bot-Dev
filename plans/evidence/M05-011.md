## Retreat (combat tests)

### Legal destinations
| Condition | Description |
|---|---|
| Adjacent | Must be adjacent to current system |
| Units present | Must have retreating player's units or controlled planet |
| No enemy ships | Cannot retreat to system with enemy ships |
| Move value | Ships with move value retreat under own power |

### Cargo
- Fighters and ground forces beyond fleet capacity removed (78.7b)
- Ships with move value retreat; others carried
- Cargo from retreating ships stays with ships

### Timing
- Announced after dice roll (78.4 before 78.5)
- Defender announces first (78.4)
- Attacker blocked if defender retreats (78.4b)
- Nobody may retreat without eligible destination (78.4c)

### Tokens
- Command token placed in destination (78.7d)
- Token comes from retreating player's pool

### Combat termination
- Retreat cancelled if opponent has no ships left (78.7a)
- Further rounds resume at Announce Retreats (78.8)
- Combat ends when one or no ships left (78.9)
