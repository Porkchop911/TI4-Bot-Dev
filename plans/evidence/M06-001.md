## Generic payment planner (production/objectives/strategy payments)

### Atomic multi-currency/disjoint-planet planner
| Currency | Source | Conversion |
|---|---|---|
| Resources | Planet cards | 1:1 |
| Influence | Planet cards | 1:1 |
| Trade goods | Player pool | 2:1 (MC) or 1:1 |

### Exhaustive small-state properties
- For small payment amounts (≤ 5), enumerate all possible payment plans
- Verify total payment matches cost
- Verify no planet exhausted twice
- Verify trade goods not over-spent

### Payment plan enumeration
```
enumerate_plans(cost, available):
    for each planet in available:
        for each currency in [resources, influence]:
            if planet_value(planet, currency) >= cost:
                yield {planet: (currency, cost)}
            else:
                yield {planet: (currency, planet_value)} + remaining
    for each combination of planets:
        if total >= cost:
            yield {planet: (currency, value), ...}
```

### Atomic payment
- All planets exhausted together
- All trade goods spent together
- If payment fails → nothing consumed
- If payment succeeds → all consumed atomically
