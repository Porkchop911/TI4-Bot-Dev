## Frequency scopes (scope keys and lifecycle transitions)

### Frequency enum
| Variant | Python value | Rust value | Scope key |
|---|---|---|---|
| `ONCE_PER_TRIGGER` | `"once_per_trigger"` | `"once_per_trigger"` | `(ability_id, ("trigger", event_uid))` |
| `ONCE_PER_TURN` | `"once_per_turn"` | `"once_per_turn"` | `(ability_id, ("turn", turn_number))` |
| `ONCE_PER_ROUND` | `"once_per_round"` | `"once_per_round"` | `(ability_id, ("round", round_number))` |
| `UNLIMITED` | `"unlimited"` | `"unlimited"` | `None` (never cleared) |

### Scope key lifecycle
| Frequency | Key created | Key cleared |
|---|---|---|
| `ONCE_PER_TRIGGER` | When ability resolves | When event resolves (end of emit) |
| `ONCE_PER_TURN` | When ability resolves | When `begin_round()` called |
| `ONCE_PER_ROUND` | When ability resolves | When `begin_round()` called |
| `UNLIMITED` | N/A | Never |

### Lifecycle transitions
| Transition | Effect |
|---|---|
| `begin_turn(active_player)` | `turn_number += 1`, `active_player = active_player` |
| `begin_round()` | `round_number += 1`, `turn_number += 1`, clear ONCE_PER_TURN keys |
| Event cancel | ONCE_PER_TRIGGER keys cleared (event didn't happen) |
