# M08-022 — Evidence (ground-force predicate vs corpus flag)

**Branch:** `wp/m08-022-titans-pds-ground-force-predicate` from `476e0c4` (M08-021 close-out, the

## Defect (from M08-020 review finding T1)

`UnitType::is_ground_force()` hardcoded `self.id() == "titans_pds2"` while its sibling
`is_structure()` reads the corpus flag. Result: `titans_pds` (Hel-Titan I — flagged
`isGroundForce` in the corpus, baseType `pds`, hits 7 / dice 1) was **not** classified as a
ground force. Before M08-020 this was masked by the over-broad invasion trigger; after it, a
planet defended solely by a Hel-Titan I falls without resistance, and on a mixed planet the
Hel-Titan can no longer be assigned casualties — an incorrect outcome for exactly one unit.

## Decision recorded (required before switching the predicate)

**Union semantics adopted:** `flag("isGroundForce") || base_type ∈ {infantry, mech}`.

Verified against the corpus at implementation time (`crates/ti4-content/content/units.json`):

| id | baseType | isGroundForce (corpus) | pre-fix predicate | post-fix predicate |
|---|---|---|---|---|
| `titans_pds` | pds | **true** | false (**defect**) | true (fixed) |
| `titans_pds2` | pds | true | true (hardcoded id) | true (via flag; hardcoded id removed) |
| `naaz_mech_space` | mech | false | true (base-type match) | true (unchanged — union keeps it) |
| `absol_naaz_mech_space` | mech | false | true (base-type match) | true (unchanged — union keeps it) |
| `pds`, `pds2` (generic) | pds | false | false | false (unchanged) |

Rationale: the Naaz space mechs are mechs that fight on planets (corpus gives them combat
stats); their ability adds ship status *in space* and does not remove ground status. The corpus
flag marks "ground force beyond the standard infantry/mech", so it deliberately omits them; a
bare `flag()` would have dropped both Naaz mechs — union semantics preserve every current
classification while adding exactly `titans_pds`.
