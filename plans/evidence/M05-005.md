## Capacity/cargo choices (from movement/transport tests)

### Load choices
| Field | Description |
|---|---|
| `capacity` | Ship's capacity (from stats) |
| `candidates` | Units in origin (space + planets) |
| `distinct` | Deduplicated by (type, damage, galvanized, source) |
| `loaded_ground` | Count of ground forces loaded |
| `loaded_fighters` | Count of fighters loaded |

### Load option format
```
Option(
    id=f"load|{index}",
    kind="load",
    label=unit_label("load", type_id, damaged) + f" from {source or 'space'}",
    payload={
        "unit": type_id,
        "system": origin,
        "damaged": bool,
        "galvanized": bool,
        "source": planet_id or None,
        "capacity_remaining": int,
        "loaded_ground": int,
        "loaded_fighters": int,
    }
)
```

### Done loading option
```
Option(
    id="done_loading",
    kind="decline",
    label="carry nothing further",
    payload={"loaded_ground": int, "loaded_fighters": int, "ground_available": int}
)
```

### No independent troop movement
- Troops only move as cargo (carried by ships)
- No separate troop movement phase
- Cargo loaded before ship moves
- Cargo unloaded in destination space area
