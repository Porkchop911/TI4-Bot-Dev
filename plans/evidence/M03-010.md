### emit method
```
emit(event, resolve):
    log.append(f"emit {event.type}#{event.uid}")
    _run_window(event, WHEN)
    if event.cancelled:
        return event
    if is_forbidden(event):
        event.cancel()
        return event
    if resolve: resolve(event)
    _run_window(event, AFTER)
    return event
```

### _run_window method
```
_run_window(event, relation):
    relation_being_resolved = relation
    resolved_here = set()
    passed = set()
    while True:
        resolved_this_pass = False
        for player in _player_order():
            if player in passed: continue
            eligible = _eligible(event, player, resolved_here)
            if not eligible: continue
            ability = _pick(eligible, event, player, relation)
            if ability is None:
                passed.add(player)
                continue
            resolved_here.add(ability.id)
            _mark_used(ability, event)
            ability.effect(event, self)
            resolved_this_pass = True
            if event.cancelled: return
        if not resolved_this_pass: return
        passed.clear()  # New info → retry
```

### Priority order
- WHEN resolves before AFTER (LRR 1.16)
- Within window: player order determined by phase (LRR 1.19, 1.20)
- Action phase: initiative order from active player (LRR 1.19)
- Strategy/Agenda phase: seating order from speaker (LRR 1.20)

### Pass/reoffer behavior
- Player passes → added to `passed` set
- Something resolves → `passed.clear()` (new information)
- Terminates when no player resolves anything in a pass

### Cancellation
- `event.cancel()` → AFTER window skipped
- `forbid()` → event treated as not happening, AFTER skipped
- Nested cancels propagate up
