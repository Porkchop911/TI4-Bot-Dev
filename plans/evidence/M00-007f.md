## Error projection (from engine/*.py)

### Error categories observed in Python source
1. **RuntimeError** — Invalid game state transitions
   - `"no strategy card set for sources {sorted(sources)}"` (game.py)
   - Content loading failures
2. **ValueError** — Invalid input values
   - Invalid option IDs
   - Invalid player references
3. **KeyError** — Missing content references
   - Unknown card IDs
   - Unknown faction aliases
4. **AssertionError** — Internal invariants
   - State invariant violations

### Error handling approach
- Python uses exceptions for game logic errors
- Rust should use Result<T, E> with typed error types
- Errors must be serializable for replay/debugging

### Canonical NDJSON error projection
```json
{
  "type": "error",

```
