## Implementation and evidence

- Split M04-015c2b before implementation because full native executable replay crosses multiple
  incompatible boundaries. This child owns only the legal shared-prefix check.
- The retained trace begins with six strategy-card selections. The imported native state offers and
  accepts those six selected IDs through `Game::with_table(... Scripted ...)`.
- Its seventh source selection is `component|expedition|secret`. The native action generator does
  not offer it, so `Table` returns `IllegalChoice::ScriptDiverged`; only the six common selections
  are recorded. This proves a source-only component action cannot be silently passed, substituted,
  or logged as native success.

## Blocking evidence for M04-015c2b2

1. The source trace offers Thunder's Edge expedition and component actions immediately after the
   shared draft. The native action generator has no such options or handlers.
2. The public snapshots list system IDs and public units but no Save 52/54 coordinates, tile layout,
   or hidden deck/setup state required to construct the source scenario's executable `Galaxy`.
3. `Dice` derives every face from native `GameRng`; it has no checked injected source-entropy stream.
4. The game driver observes `Vec<String>` event labels, whereas retained source records contain
   typed numeric-ID events with canonical payloads and lifecycle fields.

These are architecture and compatibility requirements, not a test failure that can safely be
worked around. Implementing a permissive choice adapter or copying expected events/dice afterward
would falsely report parity.
