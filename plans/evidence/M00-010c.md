## Deck entropy capture

### Shuffle structure
```json
{
  "type": "deck_shuffle",
  "deck_id": str,
  "cards": [str],
  "seed": int
}
```

### Capture points
1. **Strategy card draft**: `strategy_card_setup()` selects from `strategy_card_sets`
2. **Action card distribution**: Cards distributed to players
3. **Promissory note deck**: Promissory notes shuffled and distributed
4. **Objective deck**: Public/secret objectives shuffled and distributed

### Verification
- Every shuffle is recorded with the resulting card order
- Repeated export of the same game produces identical shuffles
- Seeds are explicitly captured for each shuffle
