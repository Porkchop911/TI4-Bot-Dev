## Bombardment (invasion/combat modules)

### Eligibility
| Condition | Description |
|---|---|
| Active system | Must be in active system |
| Ground forces present | Attacker has ground forces |
| Planet control | Planet not controlled by attacker |
| Planetary shield | Shield blocks bombardment |

### Planetary shield interactions
| Shield level | Effect |
|---|---|
| 0 | No shield, bombardment proceeds |
| 1 | Blocks 1 hit |
| 2 | Blocks 2 hits |
| 3 | Blocks 3 hits |
| 4 | Blocks 4 hits |

### Hits
- Bombardment dice = number of ground forces (usually)
- Hits assigned to planetary defense units
- Excess hits damage planet (reduce control)
- Hits on structures (PDS) first

### Bombardment process
1. Attacker declares bombardment
2. Planetary shield absorbs hits
3. Remaining hits assigned to units
4. Planet control may change
