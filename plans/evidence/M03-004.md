## Simple deciders (behavior and exhaustion errors)

### FirstOption behavior
- Always returns `choice.options[0]`
- Deterministic across all implementations
- No decline logic (even if decline is offered)
- Used as default in tests

### AlwaysDecline behavior
- Checks `option.kind == "decline"` for each option
- Returns first decline option found
- Falls back to `options[0]` if no decline offered
- Exhaustion: no exhaustion (always available)

### Scripted behavior
- Queue-based: `pop(0)` from option_ids
- Validates each wanted id against `choice.ids`
- Raises `IllegalChoice` if wanted id not offered
- Falls back to `FirstOption` when queue exhausted
- Exhaustion: queue empty → fallback activated
- Test: `Scripted(["option_1", "option_2"]).choose(choice)` must return option_1 then option_2

### SeededRandom behavior
- Uses `random.Random(seed)` (domain-separated from game RNG)
- `rng.choice(choice.options)` — uniform selection
- Exhaustion: no exhaustion (always available)
- Test: `SeededRandom(42).choose(choice)` must be reproducible

### Exhaustion error tests
| Decider | Exhaustion condition | Error behavior |
|---|---|---|
| Scripted | Queue empty | Falls back to FirstOption (no error) |
| FirstOption | N/A | Never exhausts |
| AlwaysDecline | N/A | Never exhausts |
| SeededRandom | N/A | Never exhausts |

### Oracle fixture matching
