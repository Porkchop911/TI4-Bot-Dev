## Combat setup and rounds (from `engine/combat.py`)

### Participants
- Players with ships in system (attacker first)
- `combatants(game, system_id) -> (attacker, defender...)`
- Attacker = active player

### Initiative
- Attacker rolls all dice first (78.5f)
- Dice rolled ascending by combat value (78.5c)
- Separately per value (78.5b)

### Dice
| Property | Description |
|---|---|
| `faces` | Number of faces (usually 6) |
| `hits` | Count of results ≥ combat value |
| `roll(n, reason, hits_on)` | Roll n dice, return result |

### Round sequence (LRR 78)
| Step | Description | Source |
|---|---|---|
| 78.3 | Anti-Fighter Barrage (first round only) | combat.py |
| 78.4 | Announce retreats (defender first) | combat.py |
| 78.5 | Roll dice (attacker first) | combat.py |
| 78.6 | Assign hits (each player destroys own) | combat.py |
| 78.7 | Retreat (to adjacent with units/planet) | combat.py |
| 78.8 | Further rounds (resume at 78.4) | combat.py |
| 78.9 | Combat ends (one or no ships left) | combat.py |
| 78.10 | Winner declared (or draw) | combat.py |

### Max rounds
- MAX_ROUNDS = 50 (termination bound)
- Exceeding → error (not infinite loop)
