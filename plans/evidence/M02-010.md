### Alias/category/source lookup
- **Alias lookup**: `record["id"]` or `record["alias"]` (category-dependent)
- **Category lookup**: `load(category)` — 29 categories
- **Source lookup**: `from_sources(category, sources)` — filter by expansion

### Deterministic iteration
- All index results sorted by `id` field
- `strategy_cards` sorted by `initiative` field (lowest first)
- `factions_by_complexity` sorted by `id`

### Duplicate rejection
- Same `id` in same category during load = error
- `catalogue()` returns `dict[str, UnitType]` — last writer wins (but corpus has no duplicates)
