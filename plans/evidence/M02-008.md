## Hidden views (from `engine/views.py`)

### Redaction design
- Views are `GameState` with private parts of *other* players replaced
- Size of private holdings stays visible (e.g., 4 hidden cards, not 0)
- Replacing with `HIDDEN = "?"` marker prevents lookup against real content
- Every query (`player().action_cards`, `len(...)`) works against a view
- Only code that inspects a specific card sees the marker

### Private sequences (per-player fields nobody else may read)
| Field | Python type | Rust type | Redaction |
|---|---|---|---|
| `action_cards` | `tuple[str, ...]` | `Vec<CardId>` | `["?", "?", ...]` |
| `secret_objectives` | `tuple[str, ...]` | `Vec<SecretId>` | `["?", "?", ...]` |
