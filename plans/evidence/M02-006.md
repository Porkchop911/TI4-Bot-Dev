### Sequence counters (effect scoping)
| Field | Python type | Rust type | Purpose |
|---|---|---|---|
| `combat_round_seq` | `int` | `i32` | Combat round counter |
| `production_seq` | `int` | `i32` | Production use counter |
| `activation_seq` | `int` | `i32` | System activation counter |
| `turn_seq` | `int` | `i32` | Action phase turn counter |

### Scope design principle
- **No boolean flags** for scoped effects (e.g., "is Morale Boost active?")
- **Sequence number comparison** instead (e.g., "is combat_round_seq == bonus_round?")
- Effects lapse automatically when the sequence advances
- No explicit cleanup needed — scope is implicit in the sequence number
