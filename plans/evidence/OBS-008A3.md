## Result

1. **Engine.** Each pickup (`load|…`) option now carries `Preview::certain` with one
   `Quantity::CapacityFree` delta: the hold's own remaining slots (`capacity - loaded.len()`)
   before this pickup, to one less. This mirrors `resolve`, which charges exactly one slot per
   accepted load regardless of a unit's printed `capacityUsed` — the preview states the engine's
   own charge, not a corpus lookup that could disagree with it. The "carry nothing further" decline
   option keeps no preview.
2. **Reused quantity, not a collision.** `CapacityFree` is the same LRR 16 concept OBS-008a2 already
   previews for a system's total transport capacity, here scoped to one ship's hold. The two never
   share a choice (`movement_step` vs `load_cargo`), so the shared name is the shared vocabulary the
   `tactical` family exists to give, not an ambiguity.
3. **Policy.** `tactical_decision_features`'s subtype guard (`activate_system` / `movement_step`)
   now also matches `load_cargo`; the existing `CapacityFree` delta-to-`tactical:capacity-free-*`
   mapping needed no change. No new family, no vocabulary bump.
4. **Boundaries.** Previews are `#[serde(skip)]`; no option ID, label, payload, legal set, replay
   script, or V1/V2 decision hash moves. No `DecisionContext` field is added or changed. Loading
   legality, `loadable`, and `capacity_of` are untouched.

## Focused evidence

- `transit.rs::obs008a3_load_options_preview_the_holds_own_capacity_falling_by_one`: a fresh
  capacity-4 carrier hold with an infantry and a fighter candidate. Every non-decline option
  previews `CapacityFree` `4 -> 3`; the decline option has no preview. After resolving one pickup,
  the next pickup choice's remaining option previews `3 -> 2` — the first preview's `after` is what
  the next choice's `before` actually is.
- `features.rs::obs008a3_load_options_carry_the_holds_own_capacity_falling_by_one`: a `load_cargo`
  choice with a previewed pickup and a bare decline option. `tactical:subtype:load_cargo`,
  `tactical:option-count` (2), and exact `tactical:capacity-free-{before,after,change}` (4 / 3 / -1)
  reach the policy on the pickup; the decline option carries the subtype but no consequence fact.
