## State canonicalizer (from M00 projection spec)

### Purpose
- Produce stable state/view JSON independent of internal map layout
- Enable byte-identical replay comparison across implementations
- Support deterministic hashing for integrity checks

### Canonical state format
```json
{
  "schema_version": "1.0.0",
  "phase": "STRATEGY",
  "round": 1,
  "active": "player_1",
  "players": [
    {
      "id": "player_1",
      "faction": "arborec",
      "victory_points": 0,
      "trade_goods": 3,
      "commodities": 0,
      "tactic_tokens": 3,
      "fleet_tokens": 3,
      "strategic_tokens": 2,
      "technologies": ["md"],
      "action_cards": ["action_1"],
      "secret_objectives": ["secret_1"],
      "strategy_cards": ["strategy_1"],
      "exhausted_strategy_cards": [],
      "passed": false,

    "05": {

      "command_tokens": ["player_1"],
      "planet_control": {"nestphar": "player_1"},
      "planet_units": {"nestphar": []}
    }
  },
  "decks": {
    "action_card_deck": ["action_2", "action_3", ...],
    "agenda_deck": ["agenda_1", "agenda_2", ...],
    "secret_deck": ["secret_2", "secret_3", ...],

  "revealed_objectives": [],
  "objective_deck": ["public_2", ...],
  "scored_objectives": {},
  "finished": false
}
```

### Canonicalization rules
1. Players sorted by `id`
2. Board systems sorted by `id`
3. Arrays sorted deterministically (by id where applicable)
4. `compare=False` fields excluded from comparison
5. `None` values serialized as `null`
6. Empty collections as `[]` not `{}`
7. Phase as uppercase string
8. Sequence counters included for effect scoping

### View canonicalization
- Same as state but with `HIDDEN = "?"` markers for private fields
- Viewer's own state unchanged
- Board and public state identical to state canonicalization
