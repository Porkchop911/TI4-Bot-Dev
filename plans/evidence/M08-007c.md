# M08-007c — Public planet-objective progress

## Package specification

- **Objective:** Give public planet-control objective progress a named valuation factor.
- **Oracle:** pinned `bots.py` `PUBLIC_GOALS`/`demands`.
- **Boundary:** public revealed/scored objective records and public planets only; no secrets,
  resources, exhaustions, or deck access.
- **Non-goals:** trait/specialty/structure/fleet demands, reservations, schedules.

## Implementation and verification

Unscored revealed planet-control objectives now add a named `public_planet_goal` factor to public
planet valuation. A mutation reducing the factor to 1.0 made the focused valuation test fail and
was restored.

## Compatibility evidence

The factor uses only `Observed::revealed_objectives`, `Observed::scored_by`, and public planet
metadata. Secret objectives, decks, resources, and exhaustion remain inaccessible. Trait/specialty,
fleet, structure, reservation, and schedule planning are explicitly deferred.
