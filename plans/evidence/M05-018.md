## Production payment (production/payment tests)

### Enumerate atomic disjoint payment plans
| Payment source | Description |
|---|---|
| Planet resources | Exhausted planet card → resources |
| Planet influence | Exhausted planet card → influence |
| Trade goods | Converted at 2:1 (MC tech) or 1:1 |
| Combined | Mix of planets + trade goods |

### Failed payment
- If payment fails → production consumes nothing
- Planet cards not exhausted
- Trade goods not spent
- Production not attempted

### Payment validation
1. Calculate total cost
2. Calculate available resources (planets + trade goods)
3. If available ≥ cost → payment succeeds
4. If available < cost → payment fails, nothing consumed

### Planet payment values
```
planet_value_now(game, planet, kind) -> int:
    base = planet_value(planet, kind)
    bonus = exploration.modifiers(game, planet)[kind]
    value = laws.planet_value(game, planet, kind, base + bonus)
    if kind == RESOURCES:
        value += helios_bonus  # Helios V2: +2, Helios V1: +1
    return value
```
