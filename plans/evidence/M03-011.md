## Nested emission (timing recursion)

### Depth-first nesting
- Ability effects can call `resolver.emit(inner_event)`
- Inner event fully resolves before outer window continues
- Depth-first: innermost event completes before unwinding

### Recursion bounds
- Maximum recursion depth: 100 (diagnostic failure at limit)
- Depth tracked via `resolver._depth` counter
- Exceeding limit → `CannotViolation("nested emission depth exceeded")`

### Diagnostic failure
- At limit: log current event chain
- Log: `emit {event.type}#{event.uid} (depth {depth})`
- Error message includes full event chain for debugging

### Exact trace tests
| Test | Scenario | Expected trace |
|---|---|---|
| `test_single_emit` | Single event, no nesting | `emit X#1` |
| `test_one_level` | Event A emits B | `emit A#1, emit B#2, resolve B#2, resolve A#1` |
| `test_two_levels` | A emits B emits C | `emit A#1, emit B#2, emit C#3, resolve C#3, resolve B#2, resolve A#1` |
| `test_cancel_inner` | Inner event cancelled | Outer AFTER window skipped |
| `test_cancel_outer` | Outer event cancelled | No AFTER window |
| `test_depth_limit` | 101 nested events | `CannotViolation` at depth 100 |

### Trace format
```
emit {event_type}#{uid}
  [when] {player} -> {ability_id}
  resolve {event_type}#{uid}
  [after] {player} -> {ability_id}
```

### Determinism
- Nested events resolve in registration order (within frequency constraints)
- Same input → same trace (deterministic)
- Trace logged for replay verification
