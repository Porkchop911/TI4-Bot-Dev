### What was built

- `crates/ti4-sim/src/run.rs`: `play_learned(...)` — seats every player with the `LearnedBot` of
  its faction's champion profile on a map-pool board (tile seed = game seed), per-seat derived RNG
  streams using the same discipline as `Seats::Scored`. The post-run reduction was extracted into
  one private `reduce(...)` shared by `play_with` and `play_learned` so every seat variant reports
  through the same code path. Existing `Random`/`Scored` behavior is unchanged (full suite green).
- `crates/ti4-sim/src/baseline.rs`: fail-closed panel runner — `verify_checksum` (sha256 prefix
  check per MLP plan §10), `Champions::load_checkpoint_accepted` (loads the envelope's `accepted`
  map, validates every profile for its own faction, records the source sha256), `run_panel`
  (verifies pool + champions **before** playing any game), `PanelReport`/`PanelSummary`.
- `crates/ti4-sim/examples/m09_019a_panel.rs`: the real-artifact panel with fixed parameters and a
  before/after non-overwrite proof on both inputs.
