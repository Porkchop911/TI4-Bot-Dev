## Step/run API (from `engine/game.py`)

### Game.step
| Parameter | Type | Purpose |
|---|---|---|
| `choice` | `Choice` | The legal choice to resolve |
| `option` | `Option` | The selected option |
| Returns | `StepResult` | Metadata about the step |

### StepResult
| Field | Type | Purpose |
|---|---|---|
| `phase` | `Phase` | Current phase after step |
| `active` | `Option<PlayerId>` | Active player |
| `finished` | `bool` | Game ended |
| `error` | `Option<String>` | Error message if any |

### One-decision stepping
- Each call to `step` resolves exactly one decision
- Returns after the decision, before next phase transition
- Allows deterministic replay: one decision at a time

### Round horizon
- Game continues until 10 objectives revealed or target VP reached
- Maximum rounds: bounded by game design (typically 10-15)
- `StepResult.finished` indicates game end

### Finish/error metadata
- `finished`: true when game ends
- `error`: non-null when illegal state reached
- Both checked after each step

### Event observation
- `game.events: Vec<String>` — list of event types
- `game.resolver.log: Vec<String>` — resolution log
- Events recorded for replay verification
- Log cleared between games
