## Outcome projection (from engine/game.py, engine/state.py)

### Game end conditions
- `game_over: bool` — flag in GameState
- `winner: str | None` — winning player ID or None
- Victory points tracked per player in `victory_points: dict[str, int]`

### Victory point sources (from content/public_objectives.json, content/secret_objectives.json)
- Public objectives (stage 1 and stage 2)
- Secret objectives
- Faction abilities
- Milestones
- Relics
- Technology bonuses

### Canonical NDJSON outcome projection
```json
{
  "type": "outcome",
  "game_over": bool,
  "winner": str | null,
  "victory_points": {
    "player_id": int
  },
  "final_phase": "strategy" | "action" | "status" | "agenda",
  "final_turn": int,
  "final_round": int,
  "reason": str  // "milestone", "victory_points", "surrender", etc.
}
```
