## Planet control (invasion/state)

### Claim
- Player with most units on planet claims control
- Previous owner loses control
- Control recorded in GameState.board[system].planet_control[planet]

### Previous owner
- Previous owner loses planet control
- Previous owner's units may be destroyed (if no retreat)
- Previous owner's command tokens remain

### Structures
- Structures on planet remain
- New controller may use structures (PDS, production)
- Structure abilities transfer to new controller

### Custodians hooks
- When planet controlled by all players → custodians token advances
- Custodians removal triggers agenda phase
- Hook: game.state.custodians_removed checked in phase transition

### Event order
1. Combat resolves (ground combat)
2. Planet control updated
3. Custodians check
4. Events emitted (PLANET_CONTROLLED, CUSTODIANS_ADVANCED)
