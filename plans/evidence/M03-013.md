## Event/decision hashes (versioned canonical hashes)

### Event hash
```
hash(event) = SHA-256(
    schema_version,
    event.type,
    sorted(event.payload.items()),
    event.uid
)
```

### Decision hash
```
hash(decision) = SHA-256(
    schema_version,
    decision.player,
    decision.prompt,
    decision.chosen,
    sorted(decision.offered)
)
```

### Versioned
- `schema_version` embedded in hash input
- Changing schema_version → different hash for same data
- Version bump required for any hash input change

### Unaffected by
- Memory allocation order (deterministic serialization)
- Map iteration order (sorted keys)
- Pointer addresses (not included)
- Timestamps (not included)

### Golden tests
- Same event data → identical hash across implementations
- Different event data → different hash (collision-resistant)
- Hash stable across Rust versions (no hash algorithm changes)
- Decision hash stable across game states (only decision data matters)
