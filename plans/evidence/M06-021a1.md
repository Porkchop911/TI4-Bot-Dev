## Scope and decisions

- Added a monotonically allocated, serde-transparent `FeatOccurrence` and a
  per-player `(Feat, FeatOccurrence)` ledger. New fields deserialize with empty/
  zero defaults, so existing saved state remains readable.
- Added `EventScope` to distinguish a legacy turn-scoped call from a concrete
  occurrence. Legacy callers deliberately remain on the old path until
  M06-021a2 wires each exact pause point.
- Added `EventScoreLimit`: combat occurrences consume a player's one permitted
  score; action/agenda occurrences retain that player after each accepted score
  so the remaining eligible secrets are offered sequentially. A decline closes
  the sequence without mutation.
- No emitter, replay, redaction-view, or public game-loop path changed here.
  M06-021a2 must allocate and use the occurrence at anti-fighter barrage,
  space-cannon, combat, bombardment, control-loss, pass, and agenda boundaries.
