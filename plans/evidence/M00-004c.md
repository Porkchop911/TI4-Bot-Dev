## HTTP Endpoints

### POST endpoints
| Path | Handler | Request | Response | Purpose |
|---|---|---|---|---|
| `/postkey?key=...&timestamp=...` | `_Handler.do_POST` | JSON payload (hexSummary, round, board state) | `{"commands": [...]}` | Fast path game data upload |
| `/posttimestamp?timestamp=...` | `_Handler.do_POST` | JSON payload | `{"commands": [...]}` | Anonymized game data upload |
| `/data` | `_Handler.do_POST` | JSON payload | `{"commands": [...]}` | Default game data upload |
| `/queue` | `_Handler._queue_command` | `{"action": str, ...}` | `{"queued": {...}, "id": int, "pending": int}` | Queue command for next upload |
| `/poll` | `_Handler.do_POST` | `{"log": [...], "turn": str}` | `{"commands": [...]}` | Executor poll (log + turn signal) |

### GET endpoints
| Path | Handler | Response | Purpose |
|---|---|---|---|
| `/log` | `_Handler.do_GET` | `{"log": [str, ...]}` | Read executor log |
| `/latest` | `_Handler.do_GET` | JSON payload or `{"error": "..."}` | Read latest upload payload |
| `/turn` | `_Handler.do_GET` | `{"turn": str, "received_at": float}` or error | Read current turn color |
| `/` (default) | `_Handler.do_GET` | `{"ok": true, "uploads": int, "pending": int, "features": [...]}` | Health check |

### Error responses
| Status | Condition | Response |
|---|---|---|
| 400 | Malformed JSON body | `{"error": str}` |
| 400 | Payload not an object | `{"error": "payload was not an object"}` |
| 400 | Queue command missing action | `{"error": "a command needs an 'action' string"}` |
| 404 | Unknown POST path | `{"error": "unknown path"}` |
| 404 | No upload yet (GET /latest) | `{"error": "no upload has arrived yet"}` |
| 404 | No turn yet (GET /turn) | `{"error": "no executor poll has reported a turn yet"}` |

## Server classes
| Class | Purpose | Key methods |
|---|---|---|
| `Upload` | One payload from TTS mod | `hex_summary` prop, `round` prop |
| `Bridge` | In-memory state holder | `receive()`, `queue()`, `absorb_log()`, `observe_turn()`, `take_pending()` |
| `_Handler` | HTTP request handler | `do_POST()`, `do_GET()`, `_read_body()`, `_respond()`, `_poll_payload()`, `_queue_command()` |
| `BridgeServer` | Threaded HTTP server | `start()`, `stop()`, `port` prop, context manager |
