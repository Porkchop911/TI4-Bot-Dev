## Compatibility class
- **Wire commands**: `exact` — Rust must produce byte-identical JSON for TTS compatibility (M11).
- **Lua bridge executor**: `semantic` — Rust bridge will use different mechanism.
- **Telemetry events**: `exact` — Rust must emit equivalent event stream.
- **MOD_UNIT_NAMES**: `exact` — 11 unit type → TTS object name mappings.
- **EXPLORE_DISPOSITION**: `exact` — Card resolution → TTS action mapping.
- **CARD_BOARDS**: `exact` — Card destination boards.
