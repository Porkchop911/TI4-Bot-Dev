# M00-009h1 — Deterministic initial-setup CLI/NDJSON wiring

## Package specification

- **Milestone/package:** M00-009h1, child of M00-009h; dependencies M00-009b through M00-009g.
- **Objective:** Invoke the pinned oracle read-only and write a versioned, byte-stable NDJSON
  stream for the deterministic initial-setup boundary.
- **Oracle sources/tests inspected read-only:** `engine/game.py`, `engine/content.py`,
  `engine/views.py`, `engine/choice.py`, and `engine/timing.py` at
  `37061c511a4780d4c0719e0342533a498cd4b457`.
- **Permission class:** P0 oracle inspection; P1 paths limited to `tools/oracle_export.py`,
  `tools/oracle_exporter/`, `tools/test_oracle_state_projection.py`, this evidence file, the
  corrected projection specification, and `plans/EXECUTION_STATE.md`. No network or external
  state. Outputs are rejected unless they resolve under this repository.
- **Inputs/outputs:** game ID, integer deck seed, comma-separated seats and sources in; an atomic
  ASCII NDJSON file containing a header, initial state, each redacted view, and the initial legal
  choice out.
- **Compatibility class:** exact for the input metadata and component projections; semantic for
  the bounded setup stream. It is not a complete game/event/outcome/error exporter.
- **Explicit non-goals:** playing a game, exporting a causal event stream, entropy capture,
  fixture generation, or a Rust/Python parity claim.

## Implementation

- Added `tools/oracle_export.py` and `tools/oracle_exporter/cli.py`.
- The CLI first verifies that the oracle is exactly at the pinned commit with a clean worktree,
  disables bytecode writes before import, and refuses output paths outside the Rust repository.
- It atomically writes a compact ASCII stream: deterministic header, state, one redacted view per
  seating-order player, and the initial legal choice. `--validate-schema` validates that bounded
  ordering and stream shape.
- Corrected M00-007h's internally contradictory timestamp/header draft. The stream now has a
  deterministic header rather than a timestamped JSON wrapper masquerading as NDJSON.

## Compatibility and review

This is an initial-setup exporter, not a complete playthrough trace. It does not emit live resolved
events, outcomes, or errors because the oracle's `Game.events` stores only type strings and the
existing event projector needs the resolved `Event` object. The next child, M00-009h2, is limited
to repeatability verification of this executable setup scope; later exporter work must add proper
resolver observation before any causal-trace or parity claim. Independent review is owner-waived;
no reviewer is claimed.
