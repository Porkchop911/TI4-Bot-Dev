## Workspace policy

### Edition and MSRV
- **Edition:** 2021 (all crates)
- **MSRV:** 1.85 (via `rust-version` in workspace.package)

### Lint policy (enforced via workspace.lints)
```toml
[workspace.lints.rust]
unsafe_code = "forbid"
unused_imports = "warn"
dead_code = "warn"
deprecated = "warn"
unreachable_pub = "warn"

[workspace.lints.clippy]
all = "warn"
pedantic = "warn"
nursery = "warn"
```

### Error/log conventions
- Errors: `thiserror::Error` for library crates, `anyhow::Error` for binary crates
- Logging: `tracing` for structured logging, `tracing-subscriber` for runtime filtering
- Panic: only for unrecoverable states (invalid invariants, not user input)

### Unsafe denial
- `unsafe_code = "forbid"` at workspace level
- No `unsafe` blocks permitted without explicit exception in `plans/UNSAFE_EXCEPTIONS.md`
- All `unsafe` blocks must have:
  - Safety comment explaining invariants
  - Link to relevant test or proof
  - Reference to `UNSAFE_EXCEPTIONS.md` entry

### Feature policy
- No feature-gated `unsafe` code
- Features must be additive (no feature breaks existing behavior)
- Feature matrix documented per crate

### Profile policy
- **dev:** `split-debuginfo = "packed"`, `opt-level = 0`
- **release:** `lto = "thin"`, `strip = true`, `codegen-units = 1`
- **bench:** inherits release, `lto = "fat"`, `strip = false`
