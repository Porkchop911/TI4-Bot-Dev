## Model properties (generated add/remove/control/token operations)

### Invariant properties
| Property | Description | Rust test |
|---|---|---|
| `unit_count_conservation` | Units created = units destroyed + units moved | `assert_eq!(before.total_units(), after.total_units())` |
| `token_conservation` | Tokens gained = tokens spent | `assert_eq!(before.total_tokens(), after.total_tokens())` |
| `player_count` | Number of players never changes | `assert_eq!(before.players.len(), after.players.len())` |
| `deck_size_monotonicity` | Decks only shrink (draw) or grow (shuffle) | `assert!(after.deck.len() <= before.deck.len() + max_draw)` |
| `hidden_info_safety` | No player sees another's private fields | `assert!(leaks(state, viewer).is_empty())` |
| `phase_order` | Phases advance in correct order | `assert!(phase.is_valid_transition(next))` |
| `initiative_order_stability` | Initiative order derived from cards, not stored | `assert_eq!(state.initiative_order(), derived_order)` |
| `no_orphan_units` | All units belong to a player | `assert!(all(u.owner in state.player_ids()))` |
| `no_orphan_tokens` | All tokens belong to a player | `assert!(all(token in state.player_ids()))` |
| `no_negative_economy` | No player has negative trade goods/tokens | `assert!(all(p.trade_goods >= 0))` |

### Generated operations
| Operation | Precondition | Postcondition |
|---|---|---|
| `add_unit(system, unit)` | system exists, unit valid | `unit.owner in system.units` |
| `remove_unit(system, unit)` | unit in system | `unit not in system.units` |
| `control_planet(system, planet, player)` | system has planet | `planet_control[planet] == player` |
| `place_token(system, player, token_type)` | player has token | `token in system.command_tokens` |
| `draw_card(deck, player)` | deck not empty | `card in player.hand` |
| `exhaust_planet(state, planet)` | planet not exhausted | `planet in state.exhausted_planets` |
| `ready_planet(state, planet)` | planet exhausted | `planet not in state.exhausted_planets` |

### Property-based tests
- Use `proptest` for generated inputs
- Generate valid player IDs, unit types, system IDs
- Test all operations preserve invariants
- Test edge cases (empty board, all players passed, etc.)
